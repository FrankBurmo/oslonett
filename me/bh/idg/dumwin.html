Windows For Dummies

I denne boken lærer nye Windows brukere alt det vesentligste om Windows 3.0 og 3.1 på en humoristisk og lettfattelig måte. Du får med vanlige ord innsikt i begrep som fil-og program-håndtering, hvordan du bruker kontrollpanelet, hvordan du tilpasser Windows til å passe best for deg, hvordan du kjører DOS program under Windows og mye mye annet. Lest denne boken og finn ut at du ikkebehøver å være et geni for å opptre som ett!
