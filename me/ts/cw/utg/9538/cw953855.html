Oracle lanserer Websystem

Det holder visst ikke å være markedsledende på relasjonsdatabaser. Nå skal relasjonsdatabasen Oracle7 ligge i bunn på Web-servere også. Med sin lansering av Websystem er Oracle en komplett Internett-leverandør.

KNUT GJERNES

Oracles Internett-relaterte produkter vil gå under navnet Websystem. Produktfamilien vil inkludere en Web-leser, Webstation, og en Internett-server, Webserver.

Webstation kan kjøres under Windows 95, Windows NT, Mac OS og det Unix-baserte grensesnittet Motif. Ifølge offisielle kilder i Oracle vil Webstation inneholde ting du ikke finner hos markedsledende Netscape.

Webserver er et integrert produkt som består av Oracle Web Listener, Oracle Web Agent og relasjonsdatabasen Oracle7 Server. Kombinasjonen av disse tre komponentene gjør det mulig å utvikle Web-applikasjoner som Oracle7 lagrede prosedyrer. Dette vil gi Web-applikasjonene samme skalerbarheten, portabilitet og vedlikeholdsmuligheter som Oracle7 har i dag.

LøsmunnetLarry Ellison, sjefen i Oracle, er en eksentrisk og spennende person. Han har også en tendens til å være løsmunnet når han er rundt og snakker om hist og hint. Ofte fører det til en utilsiktet prelansering.

-- Webserver skulle egentlig lanseres i slutten av oktober. Men Ellison viste Webserver på Telecom, så lanseringen er vel egentlig allerede gjort. Prisen har Ellison ikke bestemt seg for enda. Han er veldig egenrådig, og det er få avgjørelser som blir tatt uten at han godkjenner den først. Det kan til tider være frustrerende med en slik sjef, men det er spennende også, sier Harald Løvvik i Oracle Norge spøkefullt.

Integrasjonen av Oracle7 Server med World Wide Web er et nytt og spennende initiativ. Hypertekst-linker i hvilket som helst HTML-dokument kan nå peke direkte til en Oracle-lagret prosedyre, og tillater Oracle7 Server å lage dynamiske HTML-dokumenter ved hjelp av PL/SQL. Webserver støtter alle klienter som kommuniserer med HTTP.

-- Vi ønsker å være ledende på informasjonshåndtering. Relasjonsdatabasen er skreddersydd for alle praktiske ting som vedlikeholds- problematikk, backup, hvem som skal ha tilgang. Vi ønsker at kundeinformasjon, produktinformasjon og dokumenter skal kunne nåes direkte fra Web, og at brukeren skal slippe å hoppe inn i et annet verktøy for å nå disse dataene, forteller Løvvik.

KomponenteneOracle Web Listener kommuniserer på den ene siden med Internettet via HTTP og på den andre siden med Oracle Web Agent via CGI (Common Gateway Interface). Det er Web Listener som gjør det mulig å håndterer et stort antall brukere samtidig. Oracle Web Agent snakker med Web Listener på den ene siden og med Oracles flaggskip, relasjonsdatabasen Oracle7, på den andre siden.

-- Webserver er i salg fra november. Enten kan du kjøpe en pakke med Listener, Agent og databasen eller bare Listener og Agent hvis du har Oracle7 fra før. Webstation blir gratis tilgjengelig, forteller Løvvik.

                    Oracle Websystem

Webstation:

Oracles Web-leser som blir tilgjengelig før jul. Script-språket Database Markup Language skal ifølge Oracle gi applikasjonene noe intelligens.

Webserver:

Web-serveren består av Web Listener, Web Agent og Oracle7 Server. Med denne løsningen kan du utvikle Web-applikasjoner som Oracle7-lagrede prosedyrer.

KOMPLETT: Oracle er nå en komplett Internett-leverandør. Web Listener ivaretar kommunikasjonen med HTTP, mens Web Agent snakker med relasjonsdatabasen.
