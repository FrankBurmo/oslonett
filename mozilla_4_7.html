So you are using Netscape 4.7x, are you?

It looks like you are using the browser Netscape in version 4.7 or older. This site utilizes de-jure webstandards which these browsers unfortunately does not support at all. To be specific, www.oslo.net uses Cascading Stylesheets V1 (CSS1) to style the content of this site. CSS1 became a W3C technical recommendation in December 1996, and most browser vendors comply with the most important parts of the standard, at least in their > 4.0 browsers.

But Netscape does not support CSS1 in a decent way in their 4.x browsers. To get a more enjoyable and faster web experience on the Internet, we urge you to throw out Netscape 4.x, and download far better alternative browsers. They are all free. Some good options:

  • Microsoft Internet Explorer version 5.5 or better, combined with necessary Windows security patches
  • Opera 5
  • Netscape 6.1
  • Mozilla

To learn more about webstandards and browser versions, visit the homepage of the WebStandards Project
