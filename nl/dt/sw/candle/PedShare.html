Sonia's math games are fun-to-use arcade-style games for practicing basic arithmetic skills. They are copyright Computers and Learning A/S, but can be used free of charge in any private home for non-commercial purposes. In other words: Feel free to take it home to your kids.

For educational use in schools or the like, an inexpensive license (US$40) covering unlimited use within one site can be obtained from Computers and Learning A/S. For details, download and run Sonia's math games.

Note: To unpack, use an unzipper like pkunzip. Make sure you retrieve the directory structure (for pkunzip use the '-d'-option: 'pkunzip -d smg.zip'.)

Technical information: Runs under DOS on an EGA, VGA or better screen using EGA (640x350x4) 16 color graphics. Requires a mouse.
