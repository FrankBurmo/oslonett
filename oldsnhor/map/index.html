Oslonett Automatic Imagemap Service

Welcome to Oslonetts automatic imagemap service. You are now authorized to install imagemap configuration files in our Netsite Commerce HTTP server. You have access to your own imagemap files only, and you can install and edit any number of such files.

Netsite uses the most common mapfile format, originally developed by NCSA and later enhanced by a number of persons. See below for details.
