32-bits verktøyfra Microsoft

Utviklingsverktøyene
klare før Windows 95

Brukerne applauderte da Microsoft fortalte at de planla å slippe 32-bit versjoner av de viktigste utviklingsverktøyene innen 90 dager etter lanseringen av Windows 95. Nå vil imidlertid de fleste være klar før Windows 95 slippes.

KNUT GJERNES

Som kjent er Windows 95 utsatt til august. Før dette vil de fleste av Microsofts utviklingsverktøy ha kommet med en ny 32-bits versjon. Blant produktene som var ment å skulle komme innen tre måneder etter at Windows 95 var sluppet, finner vi Access database, database utviklingsverktøyet Foxpro, Visual Basic og Visual C++.

Multitasking

Blant Windows 95 egenskapene som de nye produktene vil inneholde er 32-bit pre-emptive multitasking, mutithreaded eksekvering, lange filnavn og nytt brukergrensesnitt.

Visual C++ 2.0, som allerede er på markedet, har støtte for 32-bits OLE 2.0. Den kan brukes til å skrive Windows 95 applikasjoner, men den mangler Wizard som gir utvikleren direkte tilgang til Windows 95 egenskapene, sier John Berting, sjef for programutvikling i Rheometric Scientific, til Computerworld US. Bruker man en eldre versjon av Visual C++ oppnås ikke den samme hastigheten som med 32-bits miljø.

-- Ny versjon av Access vil sannsynligvis komme samtidig med Windows 95, sier Lars Bakkhans, produktsjef for utviklingsverktøy i Microsoft. I tillegg til at den er oppdatert for 32-bits utvikling vil den også inneholde en del andre nyheter.

-- Jeg hadde aldri trodd de skulle være så nær å slippe en Windows 95 versjon av Access, sier John Berting,

-- Det produktet som er mest spennende for Windows 95 er Access, fordi 32-bits Access kommer til å bli virkelig tøft, men jeg tror ikke de kommer til å klare å holde tidsskjema de antyder, sier Ed Staffin, visepresident i Impact Software.

Beta

Databaseutviklingsverktøyet Foxpro 3.0 lanseres på utviklerkonferansen i San Diego, USA, denne uken, men slippes først på markedet i mars eller april. På samme konferanse har Microsoft planer om å dele ut beta-versjoner til deltakerne.

-- Foxpro 3.0 vil inneholde nye grafiske objekter i skjermdialogen som gjør det mulig å lage applikasjoner som vil ha Windows 95 grensesnitt, sier Bakkhans.

Versjon 4.0 av Visual Basic er fullstendig tilrettelagt 32-bits miljøene Windows NT 3.5 og den kommende Windows 95. Men man kan fremdeles kompilere 16-bits versjoner for Windows 3.1. Visual Basic 4.0 kommer i salg i mars.

En større oppdatering av verktøy for vedlikehold av SQL Server database ventes også i løpet av våren. SQL Server 95 vil ha en bedre støtte for symmetrisk multiprosessering og bedre system vedlikeholdegenskaper.
