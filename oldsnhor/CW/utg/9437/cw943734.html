Microsoft utfordrer på
server-programvare

Microsoft har samlet sine SQL, SNA, post- og administrasjonsserver i en pakke -- Backoffice. Med lave priser skal Microsoft kapre kunder fra Oracle, Novell og forskjellige Unix-leverandører.

Einar Ryvarden

Vanlige dødelige datasjefer kan ikke kjøpe Backoffice før over jul, men de 30 største kundene i Norge kan starte installering allerede neste måned. Server-programvare har ikke vært Microsofts sterkeste felt. Men med den nye Windows NT Server kaster selskapet seg ut i kampen med Novell, Oracle og alle Unix-leverandørene.

Backoffice er en prisgunstig samling av oppgradert Microsoft server-programvare. Pakken inneholder SQL Server (database), SNA Server (stormaskinkommunikasjon), Mail Server (post) og System Management Server (administrasjon).

Priskrig

-- Vi starter en priskrig med lanseringen av Backoffice. Selv for bedrifter som bare kjøper en håndfull lisenser, koster Backoffice server- og klientprogramvare bare halvparten av konkurrerende løsninger, hevder teknisk sjef i Microsoft Norge, Ole Tom Seierstad.

Microsoft mener at deres produkter blir billigere fordi man kjøper server og klientlisenser separat.

-- Skal du ha en separat Novell backupserver, må du kjøpe en ny klientlisens for hver av brukerne dine. Hos oss betaler du bare for selve serverlisensen, forteller Seierstad.

Å koble opp en bruker mot Backoffice, koster rundt 1.000 kroner for hvert Microsoft-produkt. Men etter hvert som tallet på lisenser stiger faller prisen fort, påpeker Microsoft. En serverlisens koster rundt 6.000 kroner.

Selv om få nettverkssjefer vil bytte ut sin eksisterende serverprogramvare med billigere Microsoft-programvare, betyr likevel lansering av Backoffice en ny og skjerpet konkurranse på servermarkedet. Både for nye kjøpere og bedrifter som skal foreta større oppgraderinger, vil Backoffice være en gunstig løsning.

Alle servermodulene i Backoffice kjører på Windows NT 3.5 Server -- sammen eller alene. Det er lagt opp til et betydelig samspill mellom modulene. Det viktigste er at brukere får bare en pålogging og et passord for å koble seg til alle tjenestene. Modulene kan også bruke hverandre, blant annet kan administrasjonsmodulen bruke Mail for å varsle brukere og nettsjef om feil.

Administrasjon

Alle modulene i Backoffice er enten nye eller oppgraderte versjoner. Foruten samarbeidet mellom produktene og prisingen, gir modulene i Backoffice nye muligheter.

For datasjefene vil særlig System Management Services (SMS) være et tungt argument. Under utviklingen ble SMS kalt for Hermes. Programmet gir et enklere og bedre grensesnitt for systemadministrasjon.

Fra den sentrale NT-serveren kan man sjekke klient-PCer og overta kontrollen fullstendig. Med sin egen mus og tastatur kan nettsjefene ordne problemer og installere programvare uten å vandre i gangene eller reise til kontoret der maskinen står.

SMS holder også rede på hva som er tilkoblet nettet, distribuerer programvare og overvåker ytelsen på nettet. Ved feil eller dårlig ytelse kan systemet settes opp til å varsle nettsjefen på forskjellige måter -- alt eller hvor alvorlig problemet er.

Det britiske televerket BT har vært betatester for SMS og hevder at systemet halvere antall turer til brukernes kontorer. Men SMS krever SQL Server for å lagre utstyrsoversikt og statistikk.

Også den nye SNA Server inneholder viktige nyheter. Versjon 2.1 skal gi enklere oppkobling mot IBM vertsmaskiner. Dessuten støtter den nye versjonen Appletalk og Novells IPX/SPX.

ADMINISTRASJON: I Backoffice ligger System Management Server (SMS) som gir nettverkssjefene full kontroll over alle klient-PCer fra datarommet.
