Imponert over SQL Server 95

Microsoft får skryt fra betatesten av databasen. Beta-testerene sier at ingen kan matche SQL Server 95 i enkel bruk, og administrasjon og replikering av distribuerte databaser. Det nye grafiske administrasjonsverktøyet, Starfighter, lar et sentralt konsoll administrere alt som er nødvendig.

-- Administratoren kan utføre funksjoner som å installere og slette databaser, samt å avgjøre ledig plass på den enkelte basen ved å klikke på en verktøylinje, sier en beta-tester.

En ulempe er imidlertid at Starfighter ikke ventes å støtte andre databaser.

Det er mulig å såkalte "stored procedures" i Visual Basic, og den innebygde OLE-støtten gjør at data kan nås fra alle applikasjoner som kan snakke OLE.

Dette gir enkel tilgang fra applikasjoner som Excel og Access. Slike muligheter vil ifølge analytikere gjøre SQL Server 95 til et "hett produkt".
