Annonsering, markedsføring og salg gjennom Oslonetts Web tjenere

Sist oppdatert, 20. september 1995
Oslonett startet i 1993 Norges første kommersielle Web tjener med muligheter for annonsering og kjøp og salg. Les under om hvordan du og ditt firma kan nyttiggjøre deg Web og Oslonetts kompetanse for å markedsføre varer og tjenester.
Web er et glimrende medium til å gjøre annonsering og markedsføring av varer og tjenester. Web har en del egenskaper som gjør at man kan få til mye man ikke kan v.hj.a. tradisjonelle medier som radio, TV og aviser. Dette er egenskaper som setter leseren mer i høysetet enn man er vant til fra andre passive medier, og det er derfor viktig å bruke disse egenskapene aktivt når man utformer Web annonser. Dette bør du lese mer om.

Tilstedeværelse og synliggjøring

Det å legge seg ut på Internett og Web, innebærer minst to viktige ting:
  1. Det ene er å få et sted "å være" på Internett, et sted informasjon om bedriften kan ligge. I praksis betyr dette dedikert plass i en eller annen Web server tilkoplet Internett. Noen kaller denne plassen bedriftens "hjemmeside", men informasjonen består som regel av langt mer enn bare en side.
  2. Etter at bedriften har fått et sted å være, må tilstedeværelsen synliggjøres best mulig for det som er definert som målgrupper for bedriftens profilering på Internett. Synliggjøring kan skje på en rekke måter, f.eks. ved å plassere små hyperlinkete annonser om bedriften inn i registre, kataloger og reklamekanaler i inn- og utland.
Oslonett tilbyr alle interesserte annonsører annonseplass og hjelp til å presentere bedriften og bedriftens tilbud gjennom Oslonetts Web servere. Vår sentrale Web server har for tiden (sep 1995) ca. 600.000 oppslag i uken, og er en av Europas mest besøkte. Dette gir automatisk god fokus for annonsøren. I tillegg vil vi, om ønskelig, plassere informasjon om alle annonsører inn i passende registre og "gule sider" i inn- og utland. Oslonetts egen "gule sider" katalog Kvasir er f.eks. et meget attraktivt sted å annonsere.

Statistikk

Alle annonsører hos Oslonett mottar ukentlig statistikk over oppslag mot informasjonssidene sine. Denne statistikken er meget detaljrik, og gir et godt bilde av hva som leses mest og hvor folk som leser annonsene kommer fra. Ønsker man som annonsør mer nyansert informasjon om den enkelte person som leser annonsene, er det mulig å få til ved å lage skjemaer der brukerne selv legger igjen informasjon om seg selv - nærmest en slags "digital gjestebok"!

Hvordan legger man ut annonsetekst og bilder?

Oslonett kan ta i mot tekst og bilder på de aller fleste kjente dataformater, og har spisskompetanse på utlegg av store produktkataloger med bilder. For større kataloger kan det etter behov utarbeides avanserte søkemuligheter, kryssreferansemuligheter og ekstern linking mot andre ting på Internettet.

Det hele gjøres v.hj.a. Webs hypertekstmekanismer, og på en slik måte at leseren hele tiden effektivt kan velge og finne fram til den informasjonen vedkommende er på jakt etter.

Interaksjon

En av tingene som skiller Web fra andre reklamemedier, er muligheten for toveiskommunikasjon og sterk interaksjon utover det f.eks. fjernkontrollen på tekst-TV gir deg. Det er bl.a. mulig å implementere avansert fritekst- og strukturert søking, brukerinput via grafiske grensenitt, bestillingsskjemaer for varer og tjenester og mye mer. Brukergenerert input kan sendes til annonsøren pr. elektronisk post eller evt. fax.

Kjøp og salg

Til nå har det ikke vært foretatt svært mye kjøp og salg direkte via Internettet. Dette kommer av at rutinene rundt dette har vært regnet for usikre. Nå finnes det imidlertid mekanismer som gjør dette sikrere, og Oslonett har f.eks. nylig startet den første kommersielle Web serveren i Norge som er klargjort for kjøp og salg. Kontakt oss for nærmere informasjon om hva dette innebærer.
