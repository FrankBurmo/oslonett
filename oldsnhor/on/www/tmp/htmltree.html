Filutvelgelse

Inkluder:
Ønskes kun hierarkiet vist, sender man ikke med noen filangivelse her. Ønsker man å vise filer i tillegg til directories, sender man med et regulært uttrykk (perl regexp) som match'es mot hvert filnavn. F.eks. viser ".*" alle filer, mens "\.html?$" viser alle filer som slutter med .htm eller .html.

Nedenfor kan du angi hvilke av filene som slipper gjennom filtreringen ovenfor som likevel ikke skal vises i det ferdige dokumentet. 

Ekskluder:
Det er lurt å droppe filer som slutter på ".bak" og "~" fordi disse antas å være backupfiler med utdatert informasjon. Filer som slutter på ".map" og (ofte) ".cgi" vil gi feilmelding dersom de aksesseres uten parametere fra web-klienten. Derfor bør også disse utelates. Filer som begynner med "." bør også utelates (antar at disse ikke er ment å vises fram).

Standard header og footer

Standard header og footer kan hentes fra egne filer. Headerfilen skal inneholde <head> <title>...</title> ... </head> <body...> <h1> ... </h1>. Alle forekomster av "_SERVERNAME_" og "_DIR_" i denne filen byttes ut med hhv. navn på maskinen script'et kjører på og startdirectory for innholdsfortegnelsen. Footerfilen skal inneholde </body> og </html>.
