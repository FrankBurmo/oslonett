Utleie av Web plass til tredje part - "Webhotell ® "

Det er mulig å leie seg inn i Oslonetts Internet og Web infrastruktur for å drive videreformidling av Web tjenester helt uavhengig av Oslonetts egne aktiviteter på området. Konseptet kaller vi Webhotell ® - les mer om det under.

Hvem kan benytte seg av Webhoteller?

Webhoteller er laget med tanke på bransjer og større organisasjoner som har en strengt definert målgruppe de ønsker å henvende seg til. Det kan f.eks. dreie seg om bransjer med en rekke medlemsbedrifter som alle dermed har noe til felles. Webhoteller kan ikke benyttes til generelt videresalg av annonseplass. Ordninger kan avtales med Oslonett likevel, så sant Webhotellet ikke tar inn annonsørgrupper som Oslonett jobber - eller planlegger å jobbe strategisk mot.

Hva innebærer ordningen?

Den innebærer at du i prinsippet gjør alt arbeid med datatilrettelegging på egen hånd, og dermed må du også kjøpe deg Internet tilgang på Oslonetts infrastruktur via et Oslonett Aksess abonnement.

Om du allikevel ønsker Oslonetts hjelp med HTML koding etc., vil vi kunne selge dette på ren timebasis i den grad vi har kapasitet til å utføre arbeidet.

Selve Web hotellet vil kunne kjøre på en UNIX maskin. Du kan velge mellom at tjeneren kjører på en egen, dedikert maskin, eller om du vil dele maskin med andre. Dersom du velger egen maskin kan du selv velge programvare, og du kan kjøpe inn så mye diskplass som du behøver. Oslonett står for selve innkjøpet av maskinen og fakturerer for dette separat.

Dersom du er fornøyd med å dele maskin med andre, vil dine Web sider bli plassert innenfor en av Oslonetts "hotell-tjenere".

Hva er fordelene med ordningen?

Web hotellene er å betrakte som en outsourcing av Web aktivitetene til en bedrift. Fordelene med dette er som fordeler med annen type outsourcing, men det spesielle med Internet tjenester, er selvsagt kravet til kompetanse, sikkerhet og tilgang (båndbredde). Ved å outsource Web tjenestene slipper man å betale for Internet tilgang og slipper dessuten å bekymre seg for å eksponere interne lokalnett mot "angrep" fra Internet. I tillegg får man tilgang til Oslonetts unike kompetanse innenfor Web.

Hva er Oslonetts forpliktelser?

Vi forplikter oss til å drive den aktuelle Web serveren og maskinomgivelsene den kjører på, (herunder inngår backup) på en sikker og tilfredsstillende måte. Web serveren vil om ikke annet avtales kjøres på en UNIX maskin.
