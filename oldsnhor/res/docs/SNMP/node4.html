1.1 Agent / manager modellen for nettverksadministrasjon

Svært mange produkter og rammeverk for nettverks- og systemadministrasjon er bygget etter den såkalte agent/manager modellen.

En manager er i denne sammenheng et program eller en gruppe av programmer som har ansvar for å samle inn data om ressursene i nettet og presentere og manipulere disse dataene for om mulig å stille diagnoser, varsle operatører, iverksette tiltak etc. En manager kommuniserer med agenter gjennom et veldefinert grensesnitt som f.eks. SNMP eller CMIP eller gjennom en generell API som skjuler underliggende protokoller.    

Agentene kontrollerer ressursene i nettet som skal administreres, det være seg f.eks. maskiner eller nettverksbokser som broer, rutere, huber etc. Agentene er som regel spesiallaget for akkurat det utstyret de skal kontrollere.

Hvis nå alt utstyr på nettet - både maskiner, nettverksbokser og programvare - implementerte samme administrasjonsprotokoll, ville det være mulig å ha én manager som kommuniserte med de forskjellige agentene, selv om disse kom fra flere leverandører og kontrollerte utstyr fra mange leverandører. Problemet forbundet med denne modellen, er selvsagt den store basen med utstyr som ikke oppfyller disse forutsetningene.

Det vil derfor trolig ta mange år før komplekse nettverk kan kontrolleres gjennom en eneste management protokoll.

I spesielle omgivelser er det imidlertid mulig å se at denne modellen får fotfeste, og det mest nærliggende å nevne er selvsagt rene TCP/IP baserte internett der SNMP protokollen så og si er enerådende.
