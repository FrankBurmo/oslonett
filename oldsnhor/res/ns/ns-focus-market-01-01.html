Great Circle Associates - Internet Security Firewalls Tutorial

The Internet Security Firewalls Tutorial teaches you how to build a firewall between your site and the Internet. InfoStructure Services & Technologies, Inc. - NETPROBE SECURITY SCANNER OUTPERFORMS SATAN

[logo]

NetProbe is a network security analysis program that scans a network for security holes and configuration errors -- holes and errors which an intruder could use for break-ins.

NetProbe checks for more than 85 security holes (roughly twice as many holes as SATAN), saves results for further analysis, and produces easy-to-read reports.

NetProbe executes far faster than SATAN - from a Sun SPARC-5 it can run all tests on 100 hosts in five minutes or less.

NetProbe includes telephone support and updates as new security holes are identified.
