libwww-perl-5

The libwww-perl distribution is a collection of Perl modules which provides a simple and consistent programming interface (API) to the World-Wide Web.

The latest version of the library is libwww-perl-5b7.tar.gz (104 KB) which was released Feb 5, 1996. You will need perl5.002beta2 or better to use this version.

For perl5.001m you should continue to use the old libwww-perl-5b6.tar.gz (98 KB) which was released Nov 6, 1995.

The package as well as perl itself are also available on CPAN.
