6.2 HTML editorer

En HTML editor er en spesiell teksteditor som brukes for å produsere HTML kode. Formålet med slike programmer er tosidig:

  1. skjule detaljer i HTML språket for brukeren
  2. gjøre det raskt og enkelt å skrive HTML for ukyndige
  3. sørge for at HTML koden som produseres er ihht. gjeldende standarder for HTML

Det finnes i dag flere gode slike editorer for UNIX, Mac og Windows, men det er nok slik at man må kjenne litt til HTML for å få full glede av et slikt program. Dette er noe de som lager slike programmer ofte unnlater å si, og man gir folk feilaktig det inntrykk at man presentere seg på Web og Internettet i løpet av noen få strakser vha. et slikt program.

  Dette er delvis analogt til introduksjonen av DTP (desktop publishing) -- selv om det ble lett å lage et dokument betyr det ikke at resultatet er bra! Grunnen til dette var selvsagt at det bare er de færreste som kan tilstrekkelig om layout og grafisk design.

  Allikevel må man hilse HTML editorene velkommen, selv om det er stor forskjell på klinten og hveten når det gjelder disse. Eksempler på gode slike editor, er HoTMetal PRO og HotDog.

Pekere til andre editorer finnes i slutten av denne seksjonen.

 

Mange HTML programmerere foretrekker nok allikevel å bruke sin standard editor for å produsere HTML, evt. med forskjellige tillegg som støtter opp under produksjonen av HTML kode.

Slike tillegg/biblioteker finnes i dag for Microsoft Word, Word Perfect, Emacs m.fl.
