1.2 Noen definisjoner

``Browser''

Kjært barn har mange navn -- HTML browser, Web browser og Web klient er alle ord som betyr det samme -- nemlig programmet som du benytter for å lese og navigere i World Wide Web. De to mest kjente slike programmene er NCSA Mosaic og Netscape.

``WWW server / Web server''

Et mer korrekt (men lite brukt) ord, er HTTP server. Dette er programmet som betjener Web klientenes forespørsler om å sende HTML dokumenter (og andre typer data) tilbake til klienten.

``HTTP''

HTTP står for HyperText Transfer Protocol, og er protokollen som benyttes mellom Web klient og Web server for å utveksle data.
