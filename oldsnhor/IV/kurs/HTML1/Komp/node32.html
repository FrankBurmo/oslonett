6.1 Web browsere

For ganske kort tid siden var utvalget av Web browsere relativt moderat og kvaliteten på store deler av utvalget var så som så. Alt som var tilgjengelig var dessuten gratisprogramvare som stort sett kom fra universitets- og forskningsmiljøer. I kjølvannet av den enorme interessen for Internet og World Wide Web, har det nå dukket opp kommersielle World Wide Web browsere. Svært mange av disse er bygget på kildekoden som er lisensiert fra NCSA, og disse programmene benytter derfor delvis samme plattform som det berømte NCSA Mosaic programmet.

        Eksempler på slike ``enhanced NCSA Mosaic'' finner du bla. hos Spry, SPYGLASS, FTP Software, Quadralay og Quarterdeck.

Ellers så har f.eks. både IBM og Microsoft lansert egne browsere samt andre HTML verktøy.

Den mest kjente og brukte browseren for tiden, er nok Netscape Navigator programmet fra Netscape Communications. Programmet har en del ting som ikke andre browsere har og er raskt og effektivt å bruke.

Den generelle tendensen i utviklingen av Web browsere, er at de blir mer og mer komplette ``All-In-A-Box'' programmer som kan brukes for å aksessere andre Internet tjenester. Siden Web browsere i utgangspunktet støtter flere andre tjenester, er det særlig funksjonalitet rundt elektronisk post som man ser introduseres i browserene, og samtidig forbedres stadig funksjonaliteten for de eksisterende tjenestene. Netscape Communications har f.eks. annonsert at de i neste hovedversjon av Netscape Navigator vil bygge inn postprogrammet Eudora, et state-of-the-art Internet postprogram.
