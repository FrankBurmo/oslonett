Viktig melding, lørdag 7. oktober 1995, kl. 18.30

Vi har hatt nok et diskkrash, denne gangen på en disk med mye viktig programvare, bla. Netsite Web serveren. Restore av disken er i gang, og i mellomtiden kjører denne Web serveren som en NCSA Web server. Dette betyr at mye funksjonalitet som var avhengig av Netscapes Netsite server nå er borte. Dette gjelder bla:
  • Imagemapping virker ikke
  • private hjemmeområder ala /home/bruker eller /~bruker/ virker ikke under www.oslonett.no, men kan aksesseres på samme måte fra Web serveren aksess-www.oslonett.no
  • CGI skript med navn *.cgi liggende utenfor /cgi-bin/ virker ikke
Man vil trolig også merke at denne serveren svarer litt langsommere.

Tjenestene er ventelig fullt oppe igjen i løpet av kvelden. Vi beklager det inntrufne.

For Oslonett AS, Steinar Kjærnsrød
