Informix til nettet

Nå lanserer også Informix en løsning for å koble databaser til nettet. Nye verktøy for dette ble første gang vist på Web Innovative i San Fransisco. Informix tilbyr to teknikker for å løse problemet. Selskapet har lansert Web Interface Scripts, et skriptspråk som lar brukere bygge CGI-linker (Common Gateway Interface) mellom HTML og data lagret i Informix databaser.

Informix har også gjort avtaler med fire selskaper som lager visuelle web databaseverktøy. Brukere kan benytte disse verktøyene til å lage web-sider som snakker direkte med Informix-databasen.

Informix annonserte også et partner-program. Netscape skal integrere Informix med alle sine Internett tjener-produkter.

Symantech lager API

Symantech satser på å befeste sin posisjon på vedlikeholdsverktøy i PC Lan-miljøer gjennom å slippe et sett med grensesnitt-funksjoner. Heretter skal utviklere kunne knytte egne vedlikeholdsrutiner i større miljøer sammen med Symantechs populære verktøy som vedlikeholder informasjon om nettverket.

APIene (Application Programming Interface) gjør det mulig for porgrammerere å aksessere funksjonaliteten direkte fra programmene gjennom systemkall.

Grensesnittene skal åpne opp NEF (Norton Enterprise Framework) som binder sammen produktene i Symantechs Norton Network Suite for utviklerene.

Produktet skal først brukes for å lage produkter internt hos Symatech, og ventes først å bli gitt til tredjeparts utviklere i første halvår av 1996.

Analytikere ser på Symantechs aksjoner som et forsøk på å holde på markedsandelene i forhold til Microsoft og deres Registry og lignende applikasjoner.
