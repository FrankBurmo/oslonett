Microsoft med replikering

Microsoft har lagt til replikering til sine neste releaser av sine to hoved- databaseprodukter, SQL Server 6.0 for Windows NT og Microsoft Access 95. Microsoft mener at replikering av databasenen vil gi kundene mer kontroll over den store mengden av data som lagres på datamaskinene.

Replikeringen av SQL Server lar kunden ta kopi av databasetabeller, automatisk flytte de over et nettverk til forskjellige servere, og periodisk oppdatere kopiene.

Access replikeringen gjør det enklere for den enkelte bruker å dele på informasjon.

I utgangspunktet vil databasene kun kopiere data av sitt eget slag. Det vil si Access til Access og SQL Server til SQL Server. Eventuelt kan man bruke Open Dtabase Connectivity (ODBC) grensesnitt til å overføre data til og fra andre ODBC-databaser. KOPI: Microsoft satser på replikering av sine mest populære databaseprodukter SQL Server 6.0 og Access 95.

Ny VB-konkurrent

IBM og Apple utvikler en konkurrent til Microsofts Visual Basic som kan lage Opendoc komponenter. Det nye utviklingsverktøyet, som har kodenavnet Denali, vil bruke objekt-orienterte tillegg som lar utvikleren lage Opendoc-komponenter.

Produktet vil bruke et visuelt Basic programmeringsspråk som vil ha samme syntaksen og betydning som Microsofts populære Visual Basic produkt.

Denalis compiler lar utvikleren ta eksisterende Visual Basic applikasjoner eller Visual Basic extensions (VBX) og kompilere dem for OS/2, MacOS og eventuelt andre Unix plattformer.

HP omkonfigurerer

Hewlett-Packard har lansert nye konfigurasjoner på sine Omnibook 4000 C og CT. Samtidig vil de sette ned prisen på de gamle konfigurasjonene med opptil 20 prosent. I påvente av bærbare HP Pentium maskiner, som lanseres i USA 1. juli, velger HP å oppgradere sine bærbare maskiner. Det er raskere prosessorer og større harddisker de nye maskinene kan tilby.

HP Omnibook 4000C med 100 Mhz 486 prosessor, 810 MB harddisk, 8 MB RAM og DSTN skjerm koster 31.750 kroner pluss moms. Omnibook 4000CT med samme konfigurasjon men med TFT skjerm koster 34.950 kroner pluss moms. 4000CT med 75 Mhz 486 prosessor og 340 MB RAM koster 27.600 kroner pluss moms.

Pentium maskinene som vil bli hetende 5000C og 5000CTS blir først lansert i Norge på sensommeren. (KG)
