Nyheter: Utsetter System 8.0, Økser DOS-baser, Ny SQL Server

Utsetter System 8.0

Apple har utsatt lanseringen av Copland, neste versjon av Mac-operativsystemet, til sommeren 1996. Tidligere sa Apple juni eller juli, men i romjulen måtte selskapet innrømme at System 8.0 trolig blir forsinket et helt år. Dette er svært alvorlig for Apple, for System 8 skulle sikre Apple et overtak over Microsoft Windows 95.

Apple sier at de tekniske utfordringene i Copland ble for store til å få systemet ferdig til sommeren. Copland skulle gi grunnleggende multitasking og støtter Taligents objektorienterte utviklingmiljø.

Økser DOS-baser

Borland har stoppet utviklingen av sine DOS-databaseprodukter. DOS dør langsomt, men sikkert. En ny spiker i kisten er at Borland avslutter utviklingen av dBase og Paradox for DOS. Samtidig ryker Unix-utgaven av Paradox.

Til tross for at Borland tjente 500 millioner kroner på DOS-produkter i 1994, mener selskapet at tiden er inne for å avslutte utviklingen. Fremover vil selskapet bare lage programmer for Windows 95, sier selskapet.

De meget tiltrengte utviklerne som arbeidet på DOS-produktene er allerede flyttet over til andre prosjekter. Selskapet selger nå ut lageret av DOS-produkter til reduserte priser, men lover å gi support på sine gamle programmer i lang tid fremover.

Analytikere er forbauset over Borlands beslutning, fordi selskapet tjener gode penger. Særlig dBase er populært for brukere med svake maskiner. Microsoft er snart klar med Visual Foxpro 3.0 for DOS. (ER)

Ny SQL Server

Microsoft skal lanserer en ny versjon av SQL Server til sommeren. SQL Server 95 inneholder helt nye administrasjonsverktøy. Microsoft ruster seg til krig mot SQL-database-leverandørene Oracle, Sybase, Informix. Til sommeren lanserer selskapet sin sterkt oppgraderte SQL Server 95.

Tidlig i februar går beta nummer to med et helt ny administrasjonsverkøy ut til over 1.000 kunder. Verktøyet, som forløpig lever under navnet "Starfighter", gir nye muligheter for administrasjon og replikering.

Med SQL Server 95 kan man kopiere hele databaser med et enkelt musklikk, forteller Microsoft. Med Starfighter kan man også stille inn alarmer for de fleste typer belastninger og automatisere en rekke prosesser som tidligere tok lang tid.

SQL Server 95 støtter SNMP og kan dermed kommunisere med en administrasjonssystemer som HP Openview og IBM Netview. (ER)
