Sybase for arbeidsgrupper

Sybase vil i oktober introdusere nye versjoner av sin relasjonsdatabase som fokuserer på arbeidsgrupper. Sybase planlegger å ta opp kampen med Microsoft på mindre relasjonsdatabaser. Siden bruddet i samarbeidet tidligere i år, har Microsoft og Sybase forfulgt sine egne utviklingsplaner.

Microsoft har valgt selv å utvikle sin SQL Server til å bli en fullblods relasjonsdatabase, fremfor å være avhengig av teknologiutviklingen til Sybase. Ved neste korsvei er det mulig at Microsoft døper om SQL Server til SQL95, for å unngå forveksling med Sybase.

Sybase har innsett at volum er viktig for å skape vekst, spesielt når alternativet er å sloss med Oracle som synes å ri på en oppgangsbølge.

Sybases database SQL Server 10 vil bli introdusert for Microsofts Windows NT, IBMs OS/2 og Novells Netware. Videre vil Sybase og Novell kombinere sine produkter til SQLware, tilsvarende samarbeidet mellom Oracle og Novell.

For å skape interesse blant PC-tilhengere vil Sybase sannsynligvis legge seg på samme prisnivå som Microsoft, med 189 dollar for klient-tilkobling og 1.499 dollar for databasen.

Tett integrasjon med datamaskinleverandører arbeider Sybase også med å oppnå. Rykter vet å fortelle at Compaq kan tenke seg å levere SQL-Server som en del av sitt CD-baserte programvaretilbud.

I tillegg vil Sybase legge opp til å tilpasse sine verktøy, Replication Server, Omni SQL Gateway, Open Client og Open Server tilknytningsverktøy, for Windows NT. (AH)
