Verktøy og antivirus-pakker virker ikke

Windows 95 er kompatibelt med det meste, men for enkelte programmer blir windows-oppgraderingen nådeskuddet.

Einar Ryvarden

Microsoft har lagt ned et utrolig arbeid i utviklingen av Windows 95 for å sikre kompatibilitet med eldre programvare. Men enkelte stod ikke til å redde. Microsoft hevder at en del selskaper har programmert slurvete, mens enkelte konkurrenter mener Microsoft saboterer dem.

Uansett årsak er det mange programmer som ikke fungere som de skal under Windows 95. For flere er det snakk om detaljer som tilpasning av skriveroppsettet. Mens andre forårsaker systemsammenbrudd og en del harddiskverktøy kan gjøre alvorlig skade.

På Microsofts web-server (http://www.microsoft.com) ligger det en liste med 2.500 programmer Microsoft har testet. Listen omfatter de mest populære programpakkene for både DOS og Windows samt de mest solgt spillene.

Fordi harddisk-strukturen er endret i Windows 95, må alle antivirus og harddisk-redningspakker oppgraderes. Det samme gjelder komprimeringsverktøy som Stacker og Superstor, samt kommunikasjonspakker som Laplink og Carbon Copy.

I listen advarer Microsoft spesielt mot alvorlige problemer i den norske versjonen av den populære databasen Dataease 1.1. Microsoft hevder også at det er mindre problemer med Novell Perfectoffice, Dbase 5.0 for Windows og alle versjonene av cc:mail for Windows. Også Corels Ventura 4.2 og alle Coreldraw-versjonene sliter med mindre problemer.
