METIS A.S.

METIS A.S. utvikler IT-produkter for bygging og bruk av kunnskapsmodelller av virksomheter og selskaper. Modellene kan utveksles og samvirke over nettverk og informasjonsveier.

Etableringsår: 1985

Antall ansatte: 15

Produkter og tjenester

  • METIS Base er en objekt-orientert, dynamisk plattform for utvikling av samspillende modeller og metodikk for bygging og bruk av modeller.
  • METIS GEM er METIS'metodikk. METIS GEM er et flerdimensjonalt, beskrivende språk med sterke modelleringsverktøy for å modellere organisasjoner, produkter, prosesser, systemer og andre aspekter av en virksomhet.

System Configurations

DECSTATION

For proper installation and operation of METIS Software, we require the following configuration:

Hardware Requirements:
  • Memory (RAM): Min. 12 Mbytes, preferably 16 Mbytes.
  • Disk Storage: Min. 120 Mbytes free space.
  • Monitor: 16 - 19 "high-resolution colour.
  • Keyboard and 3-button mousse.
  • Tape-drive: TK 50
  • For document outpout: Full PostScript laser printer.
  • For document input: Scanner (on agreement).
  • Connecting to Ethernet (or other, according to Customer Configuration).
  • Swarp area: At least 70 Mbytes recommended.
Software Requirements:
  • For program developement: Compilers and libraries for C, V2.1 or higher.
  • Graphic interface: X window 11.4 and Motif 1.1.3.
  • Metwork File System: NFS. (according to Customer Configuration).
  • Process Communication: ONC/RPC (Remote Procedure Calls).
  • File server system must be able to handle filenames with a lenght of minimum 64 characters.
Configuration:
  • Net must be installed (/etc/netsetup install).
  • NFS must be installed with locking enabled (using/etc/nfssetup), and running "nfsd" and "mountd". Any file-systems containing user's local runtime area must be exported and mounted on server.
  • Each client-user must be defined on the server.
