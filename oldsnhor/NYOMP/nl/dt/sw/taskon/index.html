Taskon

Taskon AS is a Norwegian company formed in 1988 for the purpose of supporting various categories of end users with individually tailored information systems by utilizing object-oriented technology. The company builds on technology developed during the past 15 years at the Center for Industrial Research and at Taskon with an investment of approximately 200 man-years. Taskon is a supplier of information systems and products for object-oriented system development.

Taskon delivers the following products with tool support:

  1. TASKON/OOram is a method and tool for object-oriented system development. With OOram, you create an object-oriented model for analysis, specification and system design. OOram provides the user with a comprehensive work environment for developing object oriented models and specification of the system. The tool provides the user with different views on a consistent model database and has automated report generation. Model synthesis is supported, so different user models may easily be put together into more detailed and complex models. This enables model reuse and large scale system solutions involving a team of developers. TASKON/OOram has code generation support for various implementation tools and programming languages. Customers on the reference list are Norwegian Telecom Research, Garex, Deutsche Bundespost and Enator Functional Systems.

  2. TASKON/Integrator for implementation of task oriented information system within offshore industry, banking/finance, insurance, public sector and international trade. TASKON/Integrator offers a development tool for modular system design with a short turnaround time for application development. The solution can easily be altered or further developed. Example applications are portfolio management systems within banking, finance and insurance, systems for handling of contracts within international trade, solutions for managing projects and Personal Information Environments. Customers on the reference list are Skandinaviska Enskilda Banken (Sweden), Norwegian Defence and Norsk Hydro.

  3. TASKON/Integrator models specialized towards different areas of application for reuse in design of system solutions. After TASKON/Integrator has been used in different projects, Taskon will generalise Integrator models in a model library for reuse. In case the models have been produced as part of a customer project, Taskon will need the consent of the customer to offer models for reuse.

  4. TASKON/Exie solution for the total business administration. The solution supports the integrated result and resource directing, including production and following up of business plans. TASKON/Exie is developed by using the tool TASKON/Integrator. The solution was released in January 1995.
