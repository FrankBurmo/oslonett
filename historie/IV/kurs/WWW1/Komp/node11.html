3.3 HTTP metoder

HTTP definerer en rekke sk. ``Methods'' eller kommandoer om vi vil. Dagens WWW klienter og HTTP tjenere brukere bare de færreste av disse. Vi skal se på de tre viktigste kommandoene.

Legg merke til at alle disse kommandoene tar et sk. URI argument. En URI kan være av type URL (se 5) eller URN, hhv. Universal Resource Locator eller Universal Resource Name.
