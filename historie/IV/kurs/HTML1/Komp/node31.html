HTML verktøy

 

Med HTML verktøy, menes programmer som benyttes for å

  • vise fram HTML. Web browsere eller Web klienter er det vanlige ordet.

  • kode HTML. HTML editorer er ordet som brukes om denne familien verktøy

  • sjekke og validere HTML kode

  • statisk oversette til HTML fra et annet format, samt dynamisk hente ut informasjon fra andre informasjonssystemer og presentere som HTML

Alt dette er verktøy som dokumentforfattere vil kunne trenge i større eller mindre grad. Dette kompendiet tar ikke mål av seg til å gi noen fyldige lister over disse verktøyene, dessuten finnes det mange gode slike lister ute på nettet. Vi skal derfor bare knytte noen kommentarer til disse verktøyfamiliene. Til slutt i denne seksjonen finnes det flere pekere til informasjon ute på Internettet om disse emnene.
