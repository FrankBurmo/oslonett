Velkommen til kurs i HTML

HTML står for HyperText Markup Language

HTML brukes til å kode hypermedia dokumenter innenfor World Wide Web på Internet.

HTML er et beskrivelsesspråk som beskriver strukturer og sammenhenger mellom de enkelte delene av et dokument.
HTML sier så godt som ingenting om fysisk utseende og layout - det er opp til programmet som tolker HTML koden og knytte en layout til de enkelte HTML konstruksjonene.
