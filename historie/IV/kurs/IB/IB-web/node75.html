«Digital Cash»

Parallellt, og nært beslektet med ovenstående aktiviteter, er det flere som ser på muligheten for å bruke «digitale penger» som betalingsmiddel på nettet, og også på hvordan man kan lage «banksystemer» som autorisasjonsinstanser for transaksjonene som må gjøres. Interesserte bør f.eks. se på aktivitetene som gjøres av firmaene DigiCash og First Virtual Holdings .
