Speiling av tjenester

Etter hvert som det dukker opp sentraliserte tjenester som søkesystemer og annonsørregistre, vil det bli behov for å speile slike tjenester for å spre nettrafikken. For eksisterende populære tjenester, f.eks. Global Network Navigator, finnes det speiltjenere rundt i verden, men dette er basert på halvautomatiske metoder.

Det arbeides også med å bake speiltjenester inn i som en integrert del av en Web server - dvs. Web serveren vet hvilke speiltjenere den har, og kan sende forespørsler til en passende av disse når trafikken er stor. Firmaet Mosaic Communications jobber f.eks. med dette.
