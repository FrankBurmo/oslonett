Kamp om Netware-klient

Microsoft og Novell med Windows 95-klient

Microsoft vant den prestisjepregete kampen om å være først ute med en Netware-klient for Windows 95 med NDS-støtte. Novell er ikke klare før i februar, men du kan laste ned beta-versjonen over Web.

Einar Ryvarden

Fra Microsoft Web-server (http://www.microsoft.com) kan du nå laste ned Netware-klienten for Windows 95 med NDS-støtte. Novell er ikke klare før i februar, men har lagt ut en beta-versjon på sin Web-server (http://netwire.novell.com).

NDS (Network Distributed Services) er Novells kronjuvel og det store salgsargumentet for Netware 4.1. Med NDS er det mulig å bygge svært store datanett fordi man har samlet database over alle brukere og ressurser. Tilgangen til brukere som ansettes, flytter eller slutter, trenger bare å forandres en gang med NDS. Det samme gjelder ressurser som skrivere.

En rekke andre produkter, blant annet postsystemer, kan også bruke NDS for å få oversikt over brukere.

Windows 95 støtter selvfølgelig Netware, det mest populære nettverksoperativsystemet, men klienten som følger med bare 16-bits, støtter ikke NDS. Dermed kan ikke Windows 95 lese NDS-databasen over brukere og ressurser i Netware 4.0 og 4.1 nett.

Kritisert

Både Microsoft og Novell ble kritisert for den manglende NDS-støtten og det utviklet seg raskt en prestisjekamp mellom de to selskapene om hvem som kom først. Microsoft vant kampen ved nylig å legge ut sin NDS-klient på Web, men kampen var ikke bare prestisje, påpeker Peter Wenderløv, produktsjef for Windows 95 i Skandinavia.

-- Den nye Windows 96-klienten er et resultat av at vi trengte en NDS-klient for Windows NT, noe Novell ikke ville utvikle for å hjelpe oss. Når vi senere så at Novell var forsinket med sin Windows 95-klient, var vi raskt klare etter mindre tilpasninger, forteller Wenderløv.

Windows NT-klienten med NDS-støtte kommer ikke før Microsoft lanserer en større oppgradering til våren. Denne oppgraderingen gir blant annet Windows NT et Windows 95-grensesnitt.

Novells klient er en full 32-bits pakke med støtte for alle funksjonene i NDS og Netware 4.1. Men brukere som trenger NDS-støtten bør trolig vente litt - amerikanske beta-testere rapporterer om mange feil og systemsammenbrudd under bruk av beta-versjonen. Den tredje store leverandøren av nettverksoperativsystemer, Bayan, er snart klar med en Windows 95-klient for deres Vines med TCP/IP og Windows NT-støtte.

Klienten de lanserer rundt nyttår oversetter TCP/IP til Vines IP-trafikk, men i løpet av mars er Bayan klar med ekte TCP/IP-støtte.
