Oracle Powerbrowser tar ledelsen

Visjonene om programvare over Internett rykker nærmere. Oracle Powerbrowser lar deg utvikle Internett-programvare med Basic-kode og Hotjava. Med i pakken ligger det også en Web-server og -- best av alt -- Powerbrowser er helt gratis.

Einar Ryvarden

Aldri har et marked utviklet seg raskere. Internett forandres fra uke til uke ettersom produkter og tjenester annonseres, den ene med mer utrolige muligheter enn den andre. Oracle tok forrige uke en uventet ledelse med lanseringen av Powerbrowser og Internett-server. Holder Oracle hva de lover, kan du i nær fremtid begynne å bruke programvare som går over Internett.

Januar

Oracle lover at Internet Server kommer i salg allerede i løpet av måneden, mens Powerbrowser kommer i januar. Dette er svært optimistisk, for Powerbrowser-versjonen du kan laste ned fra http://www.oracle.com bærer preg av å være en beta -- vesentlige muligheter mangler og stabiliteten er dårlig.

I dag finnes det hundrevis av Web-klienter bare for Windows, men Powerbrowser vil trolig presse det svakeste ut av markedet. For i tillegg til at Powerbrower er gratis, er pakken den mest omfattende Web-klient som hittil er lansert.

Kremen på kaken er den nye muligheten til å eksekvere Basic-applikasjoner. Utviklet i Oracels Powerobjects med muligheter for Microsoft OCX-tilleggene, er koden Visual Basic-kompatibel og kan lagres lokalt eller på Internett-servere. Dette åpner helt ny muligheter for rask applikasjonsutvikling.

Dessuten melder Oracle at de har fått med seg Sun og Adobe. Gjennom en ny standard kalt Network Loadable Object (NLO) vil Powerbrowser kunne kjøre både Hotjava-applikasjoner og vise frem Acrobat-dokumenter uten å laste Acrobat-leseren.

Fri deling

Powerobjects-kode gir et svært fleksibelt utviklingsmiljø, hevder markedssjef Harald Løvvik i Oracle Norge.

-- Utvikleren kan selv velge hvor mye av koden som skal kjøres over nettet. I de fleste situasjoner vil man laste ned store deler av applikasjonen til klienten og holde data og instruksjoner som skal oppdatere jevnlig på serveren, sier Løvvik.

Bare fremtiden vil vise hvor populært det blir å bruke Web-klienter som applikasjonsmiljøer. Men både Oracle og Sun påpeker mulighetene det gir programutvikler og ikke minst muligheten for informasjonsleverandører å ta seg betalt for bruk av deres tjenester. Uten registrering får du ikke tilgang til applikasjonen.

Database

Foruten støtten for forskjellige typer applikasjoner, inneholder Powerbrowser-pakken Personal Server, en miniversjon av Oracle 7-databasen. Databasen er nødvendig, for det er her Powerbrowser lagrer applikasjoner og data. I tillegg kan SQL-databasen lagre dine egne Web-sider. Et av nøkkelkonseptene i Oracles Web-lansering er muligheten til å lagre HTML-sider som SQL-objekter.

Både Powerbrowser og Oracle Internet Server innkapsler HTML-kode i et SQL-skall slik at den kan lagres i SQL-basen. Dette bringer med seg en rekke fordeler, men den aller viktigste er forenklingen dette gir i administrasjon av store Web-servere.

Oracle skryter dessuten av at den samme databasen kan flyttes uten endringer mellom forskjellige plattformer, og man får med de nødvendige verktøy for administrasjon, backup og sikkerhet. For brukere som har større Oracle-databaser selger Oracle Agens og Listner sammen i en pakke de kaller Web Option.

Både Web Option og Internet Server vil koste 40.600 kroner uansett plattform.
