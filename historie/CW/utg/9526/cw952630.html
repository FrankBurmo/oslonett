Microsoft planlegger for katastrofe

Nå hagler rettsbegjæringer mellom Justisdepartementet og Microsoft i kampen om lovligheten av Microsoft Network. Microsoft planlegger en mulig lansering av Windows 95 uten Network.

Einar Ryvarden

Microsoft har måttet bite i det sure eplet. Skulle Justisdepartementet sette seg på bakbeina og utsette lanseringen av Microsoft Network, må ikke dette få konsekvenser for lanseringen av Windows 95.

-- Klart vi har en alternativ plan, sier Greg Shaw, sjefen for Microsofts juridiske avdeling, til vårt søstertidsskrift Infoworld.

Men Microsoft har ikke fortalt hvor sent de kan vente med å ta ut Network av pakken og likevel rekke Windows 95-lanseringen 24. august.

Microsoft skal ifølge flere kilder vurdere å gi seg. Justisdepartementet henlegger saken hvis Microsoft tar ut Network fra standard-versjonen av Windows 95 og legger den inn i tilleggspakken Microsoft Plus. Plus-pakken utvider Windows 95 med en rekke verktøy og tillegg.

Det er ikke Microsoft Network i seg selv, men at klienten for den nye on-linetjenesten skal ligge ved i Windows 95-pakken.

Fordi Microsoft vil selge millioner av Windows 95-pakker bare i løpet av høsten, vil Microsoft raskt kunne utkonkurrere online-tjenester som Compuserve og American Online. Microsoft blitt etterforsket for monopolistisk forretningsdrift, men i forrige runde slapp Microsoft unna med et dask på fingeren. Det går kanskje ikke like bra denne gangen.

Krysstevning

Temperaturen i kampen mellom Justisdepartementet og Microsoft økte betydelig de siste ukene. Justisdepartementet har tydeligvis dårlig tid, for i en stevning med en rekke spørsmål, gav de bare noen dagers frist.

Microsoft kaller kravet sjikanering og har bedt en føderal domstol i New York om å få stoppet stevningen.

-- Med dagens økonomiske juss, klarer trolig Justisdepartementet å vinne en monopolistisk rettssak og tvinge Microsoft til å ta ut Network av Windows 95-pakken, mener Gervais Davis, en partner hos Davis and Schroeder, et advokatkontor i California som spesialiserer seg på denne type saker.

Neste skritt for Justisdepartementet er å kjøre en rettssak der de relativt raskt ville kunne få en midlertidig forføyning som utsetter lanseringen av Microsoft Network.

Det er denne muligheten Microsoft forbereder seg på. Det kritiske spørsmålet er hvor lenge Microsoft kan vente. Har de først støpt CD-platen eller kopiert diskettene, er det ingen vei tilbake. Microsoft må dessuten beregne med tiden det tar å transportere pakken til stedet hvor Windows 95 skal lanseres 24. august.

-- Må vi holde Microsoft Network utenfor Windows 95, fjerner vi ikonet. Det er alt for komplisert å fjerne selve koden, det blir enkelt å gjenopprette ikonet igjen, innrømmer Naveen Jain, teknisk markedsførings-ansvarlig for Microsoft Network til Infoworld.

NETWORK: Det er mulig det amerikanske Justisdepartementet tvinger Microsoft å ta ut Network fra standard-versjonen av Windows 95.
