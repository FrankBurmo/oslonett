Bli kjent med Windows 95

To bøker om Windows 95 er klare for salg. Den ene er "Windows 95 boka" fra Easy Data, den andre er "Bli kjent med Windows 95" fra IDG bøker. "Bli kjent med Windows 95" er skrevet av ansvarlig redaktør i PC World Norge Bernhard Steen. Det er en bok for både nybegynnere og mer erfarne Windows-brukere. Boken inneholder hjelp til å skreddersy Windows 95 til dine behov, tips om installasjon og tilpasning, hva som kreves av maskinvare, hvordan du kan droppe musen og bruke tastene og hvordan du kan finne fram blant dine dokumenter.

Salget kanaliseres gjennom bokhandlere, Narvesen og Elkjøp, samt en rekke andre forhandlere på landsbasis. Boken koster 98 kroner.

"Windows 95 boka" er gitt ut av Easy Data. Boken er bygget opp som et selvstudium i Windows 95. Hvert av avsnittene inneholder læretekst, tips og råd og arbeidsoppgaver. Den inneholder kapitler som "Hva er Windows 95?, Bli kjent med Windows 95, Arbeide med OLE 2" og systemverktøy. Boken inneholder ingenting om hvordan man skal installere Windows 95.

Boken kan kjøpes hos PC-forhandlere og bokhandlere for 197 kroner.

20. september kommer norsk utgave av Windows 95 for Dummies i salg. Denne boken sikter inn på undervisningmarkedet og leverer læreveiledning, overheader/foiler, øvelsesoppgaver og løsninger både i trykket form og på elektronisk medium. (KG) HJELP: Trenger du veiledning til installering av Windows 95 er "Bli kjent med Windows 95" til god hjelp.
