Borland holder koken

Lanserer 32-bits Delphi

I løpet av to uker er 32-bits versjonen av Borlands Delphi i salg. Utviklere kan glede seg over større fart i applikasjoner for både Windows 95 og Windows NT.

Einar Ryvarden

Borland holder koken i kampen mot Microsoft. Med Delphi som flaggskip konkurrerer Borland med Microsofts store flåte av utviklingsverktøy, der Visual Basic er flaggskipet. I tillegg til 32-bits versjonen av Delphi, kommer det også en 32-bits utgave av Paradox i løpet av våren.

Men Borland sliter tungt mot Microsoft og en lang serie andre leverandører, noe som rammer Dbase-brukere -- det kommer neppe noen større oppgraderinger av den gamle, ærverdige databasen.

Delphi vil bli solgt i to versjoner -- en med bare Delphi 2.0 til rundt 5.500 kroner og en klient/tjener-versjon med en rekke verktøy og Borlands SQL-database Interbase til rundt 18.000 kroner.

-- Salget av Delphi har gått langt over forventning, men har sunket noe i påvente av versjon 2.0. Salget av Paradox derimot, har falt sterkt de siste årene. Vi selger nesten ikke Dbase lenger, forteller Dag Honningsvåg, administrerende direktør hos Borland-importøren Computer 2000.

Windows 95

Delphi 2.0 kompilerer 32-bits programmer for Windows 95 og Windows NT. Kompilatoren bruker den samme motoren som Borlands C++, noe som gir optimalisert kode som går kjappere og tar mindre plass. Dette gjør det også enklere å blande C++ og Pascal-kode fra Delphi. Kompilator-feilsøking er også forbedret, og Delphi 2.0 gir forklarende feilmeldinger i stedet for den relativt meningsløse "error in statment".

Med Delphi 2.0 kan utviklere lage programmer med alle Windows 95-elementer. Fra menyen kan utviklere plukke alle grafiske elementer for Windows 95. Men overgangen til 32-bits kode koster -- den nye Delphi-versjonen kan ikke bruke 16-bits VBX-tillegg, bare 32-bits OCXer.

Dette vil være en bremse for mange utviklere som er avhengig av tredjeparts-kontrollere. Borland vil derfor forsette å selge 16-bits versjonen Delphi 1.0.

Delphi 2.0 er meget sterk på OLE 2.0 -- programmet kan både kalle opp og bruke OLE-server eller være en selv. Dermed kan man lage programmer som for eksempel starter opp Word eller egne OLE-servere. Delphi lar deg nemlig også lage OLE-servere.

SQL-database

I tillegg til selve utviklingsprogrammet inneholder Delphi 2.0-pakken den nye versjonen av Borlands SQL-database Interbase. Dermed kan man med pakken skape komplett løsninger for ganske store miljøer.

Klient/tjener-versjonen blir relativ komplett med rapportgeneratoren Reportsmith og databaseverktøyene Database Desktop og Database Explorer. Database Desktop gjør det enklere å se på og modifisere database-strukturen din, mens Desktop er et raskt og enkelt verktøy for å jobbe med innholdet i tabeller. Dessverre er Reportsmith fremdeles ganske treg.

En annen stor nyhet for utviklingen av større applikasjoner er at Borland har lagt ved Intersolv PVCS Version Manager som lar flere utviklere dele prosjekter.

For SQL-databasen har Borland lagt ved SQL Explorer og Monitor tools styrer og justerer basen. Med i pakken ligger det dessuten 32-bits drivere for de vanligste andre SQL-databasene.

32-BITS: Delphi 2.0 lar deg utvikle 32-bits applikasjoner for Windows 95 og Windows NT. Den nye versjonen lar deg også lage OLE-programbiter du kan kalle opp i andre Windows-programmer.
