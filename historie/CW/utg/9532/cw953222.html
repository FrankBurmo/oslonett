Hjelp til selvhjelp i Win95

Win95 Advisor fra Touchstone hjelper til med installeringen av Windows 95, og inneholder også også to andre Windows 95-verktøy. 24. august ble Windows 95 lansert med brask og bram. 5. august er Windows 95 i salg her i Norge. Hvor mange maskiner som skal oppgraderes er ukjent, men noen av disse vil sannsynligvis trenge hjelp.

To faser

Win95 Advisor deler installeringen i to faser. Fase en er å analysere ditt system for å finne ut hvorvidt din maskinvare lever opp til Windows 95-spesifikasjoner. Win95 Advisor kommer så med forslag til hvordan systemet eventuelt skal bygges ut.

For det andre klargjør Win95 Advisor ditt system programvaremessig slik at installeringen av Windows 95 går mest mulig problemfritt. Installeringen blir dessuten optimalisert slik at Windows 95 passer ditt system mest mulig. Win95 Advisor utarbeider en liste med ting du skal huske på, samt en batch-fil som kan automatisere hele prosessen.

Verktøy

Win95 Advisor inkluderer også to andre Windows 95-verktøy. Multimedia Benchmark sammenligner ditt systems ytelse med hensyn til multimedia-applikasjoner under henholdsvis Windows 3.1 og Windows 95. Med dette programmet kan du se hvor meget mer ditt system nå kan yte under Windows 95.

Clean&Zip rydder opp på harddisken din. Programmet er inkludert i både 16- og 32-bits versjoner.

Win95 Advisor, som vil ha en veiledende pris på 1.200 kroner, blir tilgjengelig i begynnelsen av september. Distributør i Norge er Swanholm på telefon 22 11 68 28.
