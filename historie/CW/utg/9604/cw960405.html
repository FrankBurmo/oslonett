DCE-Web

OSF er på vei til nettet med sin middleware DCE. Nylig lanserte de en løsning som knytter DCE-miljøer sammen med World Wide Web. DCE-Web består av tre elementer; Multiprotocol Server, Secure Local Proxy, og Secure Gateway.

Multiprotocol Server er en høy-ytelses web-tjener som gir sikker og rask tilgang til bedriftsdata, samt tilgang til offentlige data på web.

Secure Local Proxy gir sikker DCE-Web-tilgang ved hjelp av standard web-lesere. Secure Local Proxy fungerer som en protokollveksler -- den videresender forespørsler enten som standard http eller gjennom DCE-web-protokollen.

Secure Gateway integrerer DCE-Web med andre sikre web-protokoller. portneren gir aksess til Multiprotokoll-tjeneren gjennom DCE-autentisering basert på public key-identiteter. Portneren er laget for å gi pluggbar tilgang for multiple web-protokoller.

Ytterligere informasjon om de nye produktene finnes på: http://www.osf.org/www/dceweb/
