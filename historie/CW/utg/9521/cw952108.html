Interaktive web-sider

Hot Java fra Sun gir nye muligheter

14. juni er lanseringsdatoen for Java og Hot Java i Norge. På internettet ligger allerede en versjon av det som kanskje blir fremtiden på web. Netscape har allerede lisensiert teknologien.

Anders Løvøy

Selv om teknologiene som brukes på web i dag er egnet til mye, har de mange svakheter. Alt som skal vises på brukerens skjerm må hentes fra tjeneren, og all logikk må ligge på tjeneren. Dette fører til tett nettverkstrafikk, og setter dessuten grenser for hva som er mulig å gjøre i en web-applikasjon, all den tid klienten i praksis bare er en dum terminal.

Et Java-skript er Suns løsning på dette problemet. En kompatibel web-browser kan motta kode sammen med data og kjøre den på klientens maskin. Resultatet blir at programmerbare oppgaver kan kjøre med skikkelige hastigheter uavhengig av lasten på tjenermaskinen. På en del applikasjoner vil også trafikken på nettet reduseres kraftig.

En web-tjener basert på Java vil derfor kunne håndtere mange flere klienter enn en som er basert på HTML.

Sun har laget sin egen Java-kompatible web-browser og lagt den ut på internettet for gratis avhenting. Browseren Hot Java som er laget for Suns Solaris operativsystem, er å finne på http://java.sun.com/. Her finnes også en god del eksempler på hva Java-skriptspråket gjør i praksis.

Programmeringsspråk

Kjernen i Java-konseptet er et skript-språk som ved første øyekast kan minne om et objektorientert tredjegenerasjons-språk. Koden leses og utføres på klientens maskin. Sammen med koden kan grafikkfiler legges ved eller inkluderes.

Java støtter fleroppgavekjøring, og det er derfor en forutsetning at klient-operativsystemet også støtter dette. Hvis ikke må fleroppgavekjøring implementeres i browseren i tillegg, og det vil neppe bli gjort. Derfor utelukkes miljøer som DOS og Windows 3.x.

Som demonstrasjonene hos Sun viser, gir fleroppgavekjøringen mange morsomme muligheter. På den ene demonstrasjonen er det flere hoder som snurrer rundt og spretter vilkårlig innenfor et vindu samtidig. Kanskje ikke så nyttig i seg selv, men det viser relativt enkelt en applikasjon som det ville vært komplett umulig å kjøre på dagens teknologi.

Foreløpig er Java en del av forskningen rundt web og Internet hos Sun, men produkter vil komme fort dersom interessen er høy. Det er bare den ene browseren til Sun som finnes i dag, men Sun har planer om å lage browsere også for Windows NT, Windows 95 og Mac.

Ifølge Andreas Hope fra Multix, er Java kompatibelt med HTML og har innebygget sikkerhet gjennom bruk av SSL (Secure Sokets Layer).

Netscape

I Norge er det Skrivervik Data som vil ta seg av markedsføringen og salget av Java og Hot Java. Selv om et produkt foreligger, er teknologien så ny at konkrete planer for formen på produktet ikke foreligger.

-- Det vi har nå er en Alfa-versjon som demonstrerer konseptet, og kan brukes fritt til ikke-kommersielt bruk, sier markedssjef Edith K. Grytdal hos Skrivervik Data.

Hun mener at misjonen med gratisversjonen er å fange interessen til programvarehus og utviklere, og på den måten få frem løsninger fra tredjepartsleverandører.

Og interessen for Java er til stede. Netscape har nylig offentliggjort at de har lisensiert teknologien fra Sun, og at Java skal inkluderes i fremtidige versjoner av Netscape Navigator. Netscape skal lisensiere Java-kompilatoren, et Java foundation classes og runtime modulen til Java.

Antakelig vil teknologien bli belagt med avgifter til de som utvikler Java-browsere i framtiden, slik at sluttbrukere ikke vil se noe til lisensen. Men om dette virkelig vil bli måten Sun og Skrivervik skal tjene penger på produktet, kan ikke Grytdal si noe om.

-- Dette er helt nytt, også hos Sun. De kommer til å lage en markedsplan som vil inneholde den endelige prispolitikken, og det vil vi følge. Foreløpig eksisterer det ikke en slik plan, avslutter hun.
