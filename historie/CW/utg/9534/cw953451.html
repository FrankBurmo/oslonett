Mangel på Windows 95

Avanserte bedriftsbrukere og hjemmebrukere har tømt lagrene av Windows 95-pakker i Norge. Distributørene har lange ventelister på CD-versjonen.

Einar Ryvarden

De store distributørene og forhandlerne er tomme for CD-versjonen av Windows 95-pakken, avslører en ringerunde i bransjen. Distributørene har solgt rundt 35.000 pakker den første uken, men Microsoft har bare klart å levere rundt 30.000 pakker.

-- Microsoft tippet at 20 prosent ville ha CD-versjonen av Windows 95, og vi trodde dem. Det viser seg at CD-andelen er 40 prosent, så vi har en lang venteliste, forteller produktsjef for Microsoft Per Helge Eikenes hos Computer 2000.

Eikenes og andre aktører Computerworld kontaktet ville ikke oppgi nøyaktige salgstall.

-- Salget går bra, men vi har ikke noe lager, forteller Cinet. Selskapet får leveranser på 15-20 pakker av gangen og kjøper derfor Windows 95 fra alle de store distributørene som Scribona, Datateam/Ingram, Micro Software og Computer 2000.

Hjemmebrukere

Bransjen synes å være enige om at det er avanserte enkeltbrukere i bedriftene og hjemmebrukere som har kastet seg over Windows 95. Det store salget til bedriftene tar ikke av før om en måned eller to, tror Cinet. Bedriftene anskaffer bare noen få pakker og betaler for antall maskiner de installerer på, noe som vil løse logistikkproblemene.

Computer Resources selger like mange engelske som norske lisenser, men kan rapportere om mangel på også engelske CD-versjoner.

-- Bransjen har aldri vært igjennom en lansering som Windows 95, og det var svært vanskelig å anslå salgsvolumer. De neste ukene er en kritisk fase, mener Dag Rønsen, divisjonsdirektør hos distributøren Micro Software.

Micro Software har solgt rundt 14.500 Windows 95-pakker til forhandlere siden lanseringen 5. september, forteller Rønsen.

MANGEL: De norske distributørene har solgt rundt 35.000 Windows 95-pakker den første uken, men mangler kanskje så mye som 5.000 CD-versjoner.
