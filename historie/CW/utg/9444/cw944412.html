Oracle Workgroup Server

"SQL-databaser til folket" hadde vært et treffende slagord for Oracles Workgroup Server.

Med svært enkel installasjon og administrasjon skal avanserte brukere overtales til å kjøpe SQL-databaser for PC. Slike systemer var inntil nylig forbeholdt utviklingsavdelingene og datasjefene.

Workgroup Server er en respons på PCens popularitet. Etter hvert som PCene blir stadig kraftigere, kan PC-brukere ta over stadig flere oppgaver fra data-avdelingens stormaskiner.

Oracle skyter derfor trolig blink, for både internasjonalt og i Norge er næringslivet inne i en restruktureringsfase der det satses på mindre enheter som jobber sammen og deler informasjon.

I et forsøk på å styre bedriften bedre, ønsker ledere og medarbeidere seg oversikt over enorme datamengder, og dagens arbeidsstasjons-lignende PCer er klar for jobben. Men det er ikke dataverktøyene de fleste sluttbrukere sitter med.

Med lanseringen av Workgroup Server har Oracle senket prisene kraftig. Sammen med en billig Pentium-PC eller server tilbyr Oracle løsninger som man for få år siden måtte kjøpe en minimaskin for å oppnå. En tibruker-lisens av Workgroup Server koster 26.600 kroner.

I tillegg til den økte datakapsiteten, gir Oracle Workgroup Server store muligheter for å koble sammen ellers inkompatible systemer og dele data på en sikker måte. Fordi de aller fleste utviklingsverktøy og større datasystemer som Multisoft og Superoffice støtter SQL, kan man med en felles dataserver oppnå stor fleksibilitet.
