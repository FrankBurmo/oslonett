SQL Base versjon 6.0 klar

Gupta satser stort i markedsføringen av den nye SQL Base 6.0. I april er den nye versjonen klar i butikken. SQL Base er en av verdens mest brukte database-håndterere for PC-nettverk.

KNUT GJERNES

Gupta har mange jern i ilden for tiden. Samtidig som Gupta starter opp i Norge med eget kontor, lanserer de nye spennende produkter.

Den nye versjonen av SQL Base har spesielt styrket sin evne til å håndtere data i distribuerte miljøer og er optimalisert for PC-LAN. SQL Base kan ligge både på klient og tjener.

Det er ellers mange gode nyheter i SQL Base 6.0. Spesielt kan nevnes utvidet støtte for applikasjonsutvikling. SQL Base lagrede prosedyrer, som skrives i SAL (SQL Windows Application Language), gjør det mulig å dele og gjenbruke programkode. Dette gjør det mulig for SQL Windows programmerere å bruke de lagrede prosedyrene.

Triggers er en funksjon eller regel som aktiviserer en lagret prosedyre ved gitte situasjoner. Events er en funksjon som gjør det samme på gitte tidspunkter. Disse prosedyrene kjøres på den enkelte klient og er dermed med på å fordele regnekraften på plattformen.

SQL Base 6.0 er ifølge Gupta lettere å installere og enklere å bruke enn forrige versjon. Et nytt installasjonsprogram kan automatisere installasjonen og den konfigureres automatisk for det nettverk og servermiljø du har valgt med SQL Edit. Det skal ifølge Gupta være unødvendig med egen Database administrator.

Den nye versjonen er uforandret på pris, men du får et produkt med høyere kapasitet og ytelse.

-- Ved innlegging av data på basen, som tidligere var en svakhet, har vi nå gjort forbedringer som fører til 30 prosent høyere hastighet. Dette er et godt eksempel på at vi tar selvkritikk og kommer med forbedringer i neste versjon, sier Haakon Kayser, nylig ansatt som daglig leder i Gupta Norge.

En ny sorterings-algoritme, Postmans sort, vil forbedre ytelsen ved spørsmål mot databasen med opptil ti prosent.

Håndtering

Når du kjøper SQL Base 6.0 følger også SQL Console 2.0, et verktøy for håndtering av selve databasen. SQL Console 2.0 er en ny versjon av SQL Console, også den med flere oppdateringer.

SQL Console 2.0 nye Database Object Manager lar deg grafisk administrere alle database-komponentene. Her kan du lese hvilke brukere som er logget på, og du kan logge en spesiell bruker. Dette kan være nyttig i forbindelse med sikkerhet. Det er også her du lager, leser og administrerer prosedyrer, triggere og events.

Gupta slipper også en ny runtime-versjon av den gamle SQL Base 5.2. Dette er en database som kan spres gratis, og er beregnet på hjemmemarkedet. Den vil bli en konkurrent til Access og Paradox.

-- Dette er rett og slett en god og uortodoks form for markedsføring av Gupta. Et stort volum av SQL Base 5.2 gir god grobunn for oppdateringer til versjon 6.0, sier Kayser.

Litt senere på sommeren vil enda et produkt se dagens lys. SQL Ranger er en programmerbar dataflytter. Den kan brukes til å flytte data fra ikke-Gupta-databaser.

Gupta har solgt veldig bra i Sverige veldig lenge, nå har de bestemt seg for også å satse i Norge.

-- Det er et stort potensiale i Norge, og vi ser ingen grunner til at det ikke skal selge like bra i Norge som i Sverige. Markedsføringen av SQL Base 5.2 har ikke vært bra nok. Markedsføringen av versjon 6.0 vil vær adskillig mer offensiv, sier Birger Tenow, produktsjef i Gupta Sverige.

I markedsføringen av Gupta SQL Base 6.0 brukes en tegneserie som kan minne om det gode gamle tegneseriebladet Tempo. Kappløpet mellom Gupta og de andre database-konkurrentene er fremstilt som et bilrace mellom Granada og Dakar. I tegneserieland går Gupta av med seieren. Hvordan det vil gå i virkeligheten vil bare tiden vise.
