Windows på Unix

Drømmen som ble virkelighet

Å gi tilgang til Windows-applikasjoner på Unix-arbeidsplassene var ensbetydende med emulatorer med dårlig kompatibilitet og elendig ytelse. Med HP 500 Windiows Application Server får HP en løsning basert på samme tanke som Tektronix' Windd.

Anders Løvøy

Problemet med å kjøre Windows-applikasjoner i Unix-miljø er kjent. Ingen løsninger ga skikkelig kompatibilitet før Tektronix lanserte sitt konsept med Windd. Med HP 500 Windows Application Server har HP erkjent det samme som Tektronix, men de har laget et produkt som er vesentlig raskere.

Erkjennelsen er enkel: Hvis man skal kjøre Windows-applikasjoner bør de kjøre under Windows, og Windows kjører best på Intel.

Både Textronix og HP har en egen Intel-basert tjener stående på nettet der applikasjonene kjører under vanlig Windows. Skjermbildene blir så sendt ut til brukeren. Når brukeren benytter tastaturet eller musa blir det sendt tilbake til tjenermaskinen.

Forskjeller

Men her stopper også likhetene. HP bruker ren X til å transportere data over nettet, mens Tektronix har en proprietær protokoll. Dette innebærer at brukerene må ha Tektronix X-terminaler for å ha glede av systemet.

På tjenersiden er det motsatt. Tektronix baserer sin løsning på en standard Windows NT tjener med et multiuser-tillegg for å tillate kjøring av flere Windows-sesjoner samtidig.

HP på sin side har en egen tjenermaskin som kjører SCO Unix og en systemprogramvare som gjør det mulig for DOS-Windows sesjoner å kommunisere med skjerm og tastatur over X. Både DOS og Windows lastes oppå denne programvaren.

Systemet kjøpes "nøkkelferdig", slik at oppsett og konfigurasjon skal være så enkelt som mulig.

Hastighet

Det interessante er hva forskjellene utgjør i praksis. I en sammenligningstest som HP viste oss under lanseringen, ble en WinTics test kjørt samtidig på en HP500 Windows Application Server og en helt tilsvarende maskin med Windd.

Overraskende nok kjørte HP500 Windows Application Server flere ganger raskere enn Textronix' Windd.

Når det gjelder kompatibiliteten støtter HP 500 Windows Application Server standard mode Windows-applikasjoner, og 256 farger. Det er også mulig å ha en diskettstasjon koblet til X-terminalen som kan benyttes som A:. I nær fremtid vil enhanced mode støttes, og på nyåret vil det komme støtte for Windows 95.

Og nettopp kompatibiliteten vil være et nøkkelspørsmål i dette spillet.

Emulering av Windows har aldri blitt noen virkelig suksess, fordi man alltid er på etterskudd med nye versjoner. Det er også et tilbakevendende problem med programvare som bruker systemet på andre måter enn de som er testet.

Derfor er tanken til Tektronix og HP trolig den eneste som vil ha livets rett. Applikasjoner som er laget for å kjøre under Windows bør kjøre under Windows, og sannsynligvis tar det ikke lang tid før flere aktører er på banen med tilsvarende løsninger.

HP 500 Windows Application Server

Systemet er basert på en egen tjenermaskin som står på nettet der Windowsapplikasjoner kjører under Windows. Input fra brukeren og oppdatering av skjermen sendes over nettet gjennom X-protokollen. Dette gjør at standard X-terminaler kan brukes.

Tjenermaskinen kjører SCO Unix i bunn. Oppå den kjører Xifier fra Locus. På toppen av den lastes DOS og Windows, og til slutt Windows-applikasjoner.

Foreløpig støttes bare Standard mode Windows applikasjoner, men en versjon 1.1 som støtter Enhanced mode vil bli gjort tilgjengelig som en gratis oppgradering om relativt kort tid.

Versjon 2.0 som er beregnet å komme fem måneder etter 24. august, vil inneholde støtte for Windows 95.

En løsning med programvare og maskinvare koster 122.060 kroner for 15 brukere, og 184.960 for 30 brukere.
