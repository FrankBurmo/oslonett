Ny SQL Server i sommer

Microsoft forenkler administrasjon i versjon 6.0

Data replikering, parallelle databaser, støtte for symmetrisk multiprosessering og full OLE automatisering -- dette er noen av overskriftene til den neste versjonen av SQL Server fra Microsoft.

Anders Løvøy

De hadde ikke hatt betaen lenge hos Microsoft Norge da Computerworld kom på besøk for å titte på nykommeren. I løpet av en time hadde Microsoft satt opp tre SQL-servere, og installert replikering og speiling for demonstrasjonsformål. Dette viser at de har stor tro på det nye produktet.

Versjonen Microsoft har mottatt kalles markedsbeta 1, og starter sluttspurten før produktet etter planene slippes til sommeren. Datoen blir avhengig av tilbakespill fra betatesten.

Grønt lys

I administrasjonssystemet til SQL Server 6.0 har Microsoft virkelig lagt seg i selen for å gjøre ting enkelt. Gjennom brukergrensesnittet kan det meste gjøres gjennom pek og klikk, dra og slipp. Enkle visuelle symboler brukes for å vise og endre status. I oversikten over tjenere, visualiseres statusen på tjeneren med trafikklys. Er det grønt lys, virker tjeneren.

Enkle musekommandoer gir oversikter over påloggede brukere, hvilke oppgaver som kjøres, og grafer som viser belasting på maskinen. Alt vedlikehold gjøres gjennom det samme grafiske verktøyet.

For å lage egne spørsmål mot databasen benyttes SQL og VBA (Visual Basic for Applications), som er Microsofts felles makrospråk for alle standardprodukter. Administratoren kan forhåndsdefinere spørsmål og tidsstyre disse gjennom enkle verktøy.

Replikering

-- SQL Server 6.0 er designet som en enterprise databaseserver, sier Ole Tom Seierstad, som fremhever replikering som en viktig del av det å være en enterprise-database.

Replikeringen foregår på tabellnivå, og administrasjonen av dette er like enkel som annen administrasjon i betaen. Man drar databasene som skal replikeres over i et eget vindu, og definerer replikeringsavhengigheter omtrent som man definerer relasjoner i et relasjonsdiagram.

På selve relasjonen defineres styreverdier for selve replikeringen, som for eksempel tidsstyring. Replikereing kan defineres mot alle databaser som støtter ODBC, ifølge Seierstad.

Speiling av databasen defineres på en tilsvarende måte, og gjør at man fortsatt er operasjonell dersom en tjenermaskin går ned. Dette er funksjonalitet som Microsoft mener skal åpne for kjøring av virksomhetskritiske applikasjoner.

Støtte

I og med at Microsoft har laget en database beregnet på virksomhetskritiske applikasjoner, stiller dette nye krav til støtteapparatet. Derfor innvies et nytt "system down"-støttesenter i England til høsten. Her skal det være systemstøtte døgnet rundt, med mulighet til å få laget rettelser på blokkerende feilsituasjoner.

Microsofts strategi går ut på at det er løsningsleverandørene som skal ha den direkte brukerkontakten, og ta de problemene som kan løses på stedet. De løsningsleverandørene som er definert som partnere av Microsoft i denne sammenhengen er AT&T, ICL, Digital, NetCenter og HP.

Microsoft har store forhåpninger til salget av SQL Server 6.0, ikke bare på grunn av produktet i seg selv, men også fordi nyutviklede løsninger kan åpne nye markeder.

-- Firmaer som Rubicon, Multisoft og Software Innovation lager åpne løsninger basert på SQL-server, forteller Ole Tom Seierstad. Han mener at dette vil bidra til å åpne nye markeder.
