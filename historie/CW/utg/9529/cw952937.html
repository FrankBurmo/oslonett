Utfordrer Visual Basic

Oracle Power Objects endelig i salg

Med Power Objects skal Oracle knuse Visual Basic. Power Objects gir bedre objektorientering, database-konnektivitet og flyttbarhet. Med seg har Oracle Microsofts erke-fiender Apple og IBM.

Anders Løvøy

Markedet for visuelle programmeringsverktøy domineres av Microsoft og Visual Basic. Selv om Delphi fra Borland er et godt produkt, ser det ikke ut til at de klarer å rokke ved Microsofts posisjon.

Nå drar imidlertid tre mastodonter i bransjen sammen for å ta over hegemoniet. IBM og Apple spiller på lag med Oracle for å få programvare som kjører på deres plattformer også. Sammen kan disse tre utgjøre en høyst reell trussel mot Microsofts dominans.

Kjent

Alle som har programmert i Visual Basic vil raskt kjenne seg igjen i Oracle Power Objects. Som i Visual Basic foregår programmeringen gjennom å dra og slippe objekter på skjermbilder, og programmere hendelser og prosedyrer i språket Basic. Standardverdier og egenskaper settes i "properties", og skjermbildene kan raskt testes fra selve utviklingsmiljøet.

Men Power Objects er i tillegg stappet full av databasefunksjonalitet. Definisjon og kopiering av tabeller, dra og slipp for å flytte felt over til skjermbilder, og enkel programmering for å inntasting og visning av data.

Til slutt kan selve applikasjonen genereres, og resultatet blir en kjørbar fil som kan distribueres fritt. Dersom du velger den medfølgende databasen Blaze, kan applikasjonen distribueres uten noen ekstra kostnader for brukeren. En liten rosin i pølsa: du slipper å tenke på den evinnelige vbrun300.dll som har satt grå hår i hodet på mange.

Ellers er typen database avhengig av hvor mye du er villig til å betale. Skal du implementere en nettverksløsning med flere brukere, må du opp i en mer profesjonell versjon av verktøyet. Klient/tjeneste versjonen av verktøyet har innebygget støtte for Oracle 7, ODBC samt Microsoft og Sybase SQL Server.

Håndteringen av klasser gir også nye muligheter. Klassene samles i klassebiblioteker som er godt egnet for gjenbruk og som maler i skjermbilder.

Internett

World Wide Web står sentralt i markedsføringen og salget av Power Objects. På Oracles hjemmeside kan du allerede nå hente ned en full versjon til utprøving i 90 dager. På sikt skal også bestilling skje via Internettet. Foreløpig kommer en pakke i posten på vanlig måte etter bestilling.

Det skal også opprettes et Internett programvarehus for klassebiblioteker til Power Objects. Bidragsytere sender inn biblioteker som Oracle godkjenner og klassifiserer. Deretter blir de lagt på en Web-tjener som kunder kan besøke.

På Web-sidene skal det ligge omvisninger i hva klassebibliotekene gjør, og produsenten av biblioteket mottar royalties ved bestillinger. Dette skal skape blest og miljø rundt Power Objects.

På grunn av flyttbarheten -- kjørbare filer kan genereres både på Windows, Mac og OS/2 -- har IBM og Apple også meldt seg på for å delta i utviklingen av klassebiblioteker. Begge disse savner skikkelige verktøy som genererer applikasjoner for sine plattformer, og ser på Power Objects som midt i blinken.

Derfor kan vi vente oss et skikkelig kjør for å få Visual Basic-programmerere over på Power Objects. Svaret på om det holder får vi først når Microsoft plukker opp hansken med versjon 4.0 av Visual Basic. 

                    Oracle Power Objects
Fra Oracle betegnet som en Visual Basic killer. Er et verktøy for applikasjonsutvikling beregnet på små til mellomstore oppgaver. Oracle Power Objects inneholder bedre håndtering av objekter og klasser enn Visual Basic, noe som forenkler gjenbruk av kode.

Den tette koblingen mot databaser forenkler utviklingsarbeidet forbundet med enkle databaseapplikasjoner.

Pris:

Oracle Power Objects utviklingsversjon : 3.300 kroner
Klient/tjeneste utviklingsversjon : 16.500 kroner
Runtime-versjon: gratis ved bruk av Blaze, ellers behøves runtime-versjon av databasemotor.

Databasestøtte:

Blaze, Oracle Personal 7 (liten versjon)
Blaze, Oracle 7, ODBC samt Microsoft og Sybase SQL Server

Grensesnitt:

Støtter OCX, OLE2 og DLL

Tilgjengelighet:

Rundt 20. august for Windows og Mac. OS/2 versjon kommer noe senere. Se http://www.oracle.com/
