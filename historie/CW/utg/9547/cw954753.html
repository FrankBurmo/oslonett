Lisensierer Java

Flere store programvare-leverandører har skrevet under avtale med Sun om å lisensiere Java. Suns programmeringsspråk for Internettet finnes fortsatt kun i beta-versjon. Tidlig neste år vil versjon 1.0 være på markedet. Men flere programvareleverandører skriver nå avtale med Sun om lisensiering av Java. Adobe skrev avtale med Sun i forrige uke. Adobe vil integrere Java med programmene Acrobat og Pagemill.

Også Microsoft vil samarbeide med Sun. Og en eventuell kobling mellom Java og Visual Basic vil sannsynligvis sikre suksessen for dem begge.

Borland har påbegynt utviklingen av et Delphi-lignende utviklingsmiljø for Java-applikasjoner. Første versjon skal være klar før sommeren 1996. (KG)
