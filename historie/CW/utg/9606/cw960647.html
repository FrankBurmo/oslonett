Gratis Web-surfing

Microsoft og Telenor tilbyr nettkonto. Microsoft og Telnor har inngått et samarbeid der brukere av Windows 95 og Microsoft Internet Explorer Web-klient kan få en måneds gratis ubegrenset tilgang til internett. Tilbudet gjelder folk som plukket opp registeringskort på Software 96-messen eller som kjøper Windows 95-pakker fremover. Telenor mener avtalen vil skaffe dem flere internett- abonnenter, mens Microsoft håper å stjele brukere fra Netscape.

Microsoft håper å gjøre liknende avtaler med norske PC-leverandører for å installere Windows 95 på maskiner de selger som kobler seg rett opp mot Telepost Internett (gamle Telepost). Salgssjef hos Microsoft Norge, Terje Gjøseter, presiserer at selskapet er i ferd med å forhandle frem liknende avtaler med andre internett-leverandører her i Norge. (ER)
