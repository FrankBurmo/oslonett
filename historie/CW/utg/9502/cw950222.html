Next Big Fish

Microsoft skal på fisketur med Progress. Fangsten blir et utviklingsverktøy som tar med seg det beste fra Visual Basic og Progress' Application Development Environment. Anders Løvøy

Det ventes at Microsoft Corp. i neste uke vil lansere planene til det nye verktøyet som har fått kodenavnet Next Big Fish. NBF skal være svaret på konkurransen fra produkter som SQL Windows, Project X og PowerBuilder.

Visual Basic har blitt en stor suksess for utvikling av mindre applikasjoner med enkle og lokale databaser. Den enkle måten å lage grafiske applikasjoner på, og den store tilgangen på tredjepart VBX moduler, har gitt VB en solid posisjon.

Det faktum at VB tolker programkode i BASIC under kjøring, har imidlertid ført til at programmer går tregt. Det er også andre begrensninger i VB som har ført til at andre verktøy har blitt foretrukket i større sammenhenger.

I NBF skal BASIC byttes ut med programmeringsspråket til Progress. I tillegg skal databasekonnektiviteten bedres. NBF vil sannsynligvis være tett integrert med Microsofts Back Office pakke som inneholder SQL Server 95. Det er også meningen at databaser som Oracle7 og Sybase SQL Server System skal supporteres.

Priser og leveransedatoer for verktøyet er ikke tilgjengelig.

Verken Microsoft eller Progress ønsker å kommentere opplysningene.
