Til folkevogn-pris

Microsoft SQL Server seiler i 1995 opp som en formidabel konkurrent til Oracle. -- Microsoft er i Norge mest kjent for sine PC-programmer. Hvordan håndterer den norske organisasjonen mer avanserte programmer som SQL Server?

-- Etter lanseringen av Microsoft Backoffice som inneholder både Windows NT og SQL Server, høsten 1994, har Microsoft virkelig satt fokus på organisasjonens fellesbehov. Backoffice vil være i direkte konkurranse med Oracles produkter, men er i motsetning til Oracle Rolls Royce til folkevogn-pris, hevder Anders Føyen, ansvarlig for assistanse på SQL Server.

-- Hvem er det Microsoft tilbyr Backoffice?

-- Det er først og fremst kundene vi tilbyr Backoffice. Mange har benyttet mindre databasesystemer som Access, men disse får problemer med mer enn 20 samtidige brukere. Å erstatte Access med SQL Server er enkelt. På Digitals Alpha-maskiner får SQL Server nærmest ubegrenset utbyggingsmulighet. Vi har ansatt 500 spesialister på databaser som vil sørge for at SQL Server utvikles til et virkelig attraktivt produkt. Lanseringen av neste versjon, SQL-95, vil fjerne de fleste innvendinger som f.eks. mangel på replikering, sier Anders Føyen.

-- Hva med programvare og kompetanse?

-- Alle som kan Sybase vil kunne hjelpe. Ellers er vil Netcenter og Microsoftware bidra med salg og kompetanse. Det som gjør Backoffice spennende, er driften, som er mye enklere og rimeligere enn alternativene. Ved hjelp av lagrede prosedyrer kan en bruker starte Excel på serveren som deretter sender resultatet tilbake. Enkelheten og integreringen med de andre Microsoft-produktene gjør fremtiden for SQL Server lysende, fremhever Anders Føyen. (AH) SKAL: Microsoft Backoffice med SQL Server skal med ny funksjonalitet, rimelig pris og enkelhet i drift bli en alvorlig konkurrent til Oracles
