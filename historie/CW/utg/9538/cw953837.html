Propritære Microsoft

Jim Clark utfordrer Bill Gates

LONDON: -- Microsoft er propritære fordi de ikke publiserer sin kildekode. Vi vil publisere alt vi gjør, det er slik standarder skapes på Internettet, sier Jim Clark, grunnleggeren av Netscape.

Roar Nerdal

Det store slaget om Internett står om hva som blir gjeldende standard for handel- og pengetransaksjoner. I forrige uke lanserte VISA og Microsoft STT-teknologien (Secure Transaction Technology). Selv om STT blir gjort tilgjengelig for alle kortselskaper, finansinstitusjoner, programvareutviklere og andre som er tilknyttet Internett, er ikke alle kredittinstitusjonene fornøyd med den rollen Microsoft spiller.

Microsoft vil offentliggjøre spesifikasjonene for STT, men de vil ikke oppgi selve kildekoden.

Mastercard og Netscape

Blant de som ikke støtter STT er Mastercard og Netscape. Netscape har selv lansert Secure Courier-programvare som ikke er kompatibelt med STT. Men Netscape sier at de vil gjøre kildekoden sin tilgjengelig for alle. Dermed kan programvareselskapene selv implementere denne teknologien inn i sine applikasjoner, uten å måtte være styrt av Microsoft.

Bomavgift

Mike Homer, markedsdirektør i Netscape, hevder i Financial Times at Microsoft vil kreve avgifter for tredjeparts programvareutviklere dersom de vil bruke STT-teknologien. Dermed kan Microsoft kreve en «bom-avgift» for hver transaksjon som blir gjort på nettet.

Jim Clark, grunnlegger av Netscape og tidligere styreformann i Silicon Graphics, er meget kritisk til den rollen Microsoft er tiltenkt.

-- Microsoft er propritære. Jeg tror ikke folk er villig til å betale Microsoft for hver gang de kjøper eller selger noe på nettet, sier Clark.

Med seg har han IBM og Mastercard. Dermed har vi to ulike standarder for økonomiske transaksjoner på Internettet. Og Microsoft kan muligens for første gang gå på et skikkelig stortap.

                    Netscape

Startet

April 1994 av Jim Clark, grunnleggeren av Silicon Graphics og Marc Andreessen, studenten som utviklet Mosaic.

Formål

Netscape skal bli hovedleverandør av åpne programmer som lar folk og bedrifter utveksle informasjon og drive kommersiell handel på Internett og andre globale nettverk.

Programmer

Netscape Navigator er den mest benyttede browseren på Internett. Plattformuavhengig. Inkluderer Secure Sockets Layer som er en åpen protokoll for sikkerhet på Internett.
Netscape server line gir selskaper eller personer muligheten til å sette opp servere for Internett-tjenester. Denne produktlinjen inkluderer Netscape Communications Server, Netscape Commerce server, Netscape News Server og Netscape Proxy Server.
The Netscape Internet Application er en produktlinje utviklet for selskaper som vil drive kommersiell handel på Internett.
