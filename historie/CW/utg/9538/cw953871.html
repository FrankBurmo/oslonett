Sunsoft leverer alternativ til SCO

Millbrook: -- Å komme først, er det viktigste i dagens IT-marked, fremhever David Spenhoff, markedsansvarlig for Solaris i Sunsoft. Millbrook testbaner var derfor et velegnet sted for å lansere Solaris Base Server for Intel-maskiner. Mens SCO først vil levere i 96, kan Multix levere fra lager.

Ahlert Hysing

-- Dette er et driftsmiljø for små og mellomstore bedrifter som krever enkelhet, men samtidig et robust UNIX-miljø, sier David Spenhoff.

Sunsoft er Suns programvare-bedrift med mål å markedsføre sine produkter til Sun, kloneleverandører, Intel-leverandører og andre interessenter. I Norge er det kompetansefirmaet Multix som sørger for distribusjonen.

Ikke grafisk

Solaris Base Server er for tilhengere av UNIX på Intel som ønsker seg et avansert men samtidig enkelt driftsmiljø. For å klare det har Sunsoft renonsert på kravene til et grafisk miljø.

-- Prisen er tilpasset kundegrunnlaget. 8.830 kroner for ubegrenset antall brukere kan få andre vise til. Med over 100 brukere er Solaris Base Server priset til under en fjerdedel av konkurrerende miljøer, sier Rolf Rennemo, daglig leder i Multix.

Base Server benytter menyer for å administrere miljøet på et enkelt brukerhjelpemiddel. Rullegardinsmenyer, knapper, oppsprett-vinduer og skjermformularer er et resultat av lærdommen fra det grafiske miljøet. Minimumsverdier letter systemadministrasjonen for små miljøer uten for mye ekspertise.

-- Base Server er for flerbrukermiljøer, spesielt tilhengere av SCO-applikasjoner, og avdelinger av store bedrifter som ønsker sentralisert administrasjon, sier David Spenhoff.

Typisk eksempel er forsikringsagenter som administrerer en portefølje med kunder for et stort forsikringsselskap. Den tekniske administrasjonen av Solaris-maskinene gjøres fra sentralt hold via Suns system og nettverksadministrasjon Solstice.

-- Det er 16 prosent vekst i markedet for små bedrifter. For Sunsoft er dette et viktig marked. Min tannlege vurderer å benytte en Solaris-maskin for å legge ut avtaleboken sin på Internett, fortsetter David Spenhoff.

Fire

-- Det er fire bruksområder for IT-teknologi. Datasentre, avdelingsvise klient/tjener-miljøer, bordmaskiner samt nomader og konsumenter. Solaris vil kunne tilfredsstille de tre øverste nivåene, Hot Java det laveste og mest voluminøse, uttaler Scott McNealy, president og administrerende direktør i Sun.

-- Vi har over to millioner kunder på Solaris-miljøer, sier Julian Lomberg, europeisk salgssjef i Sunsoft.

Solaris Base Server er først og fremst Solaris, men den har et lite fotavtrykk, dvs. 12 MB hukommelse og 100 MB platelager. Dette kan synes mye, men sammenlignet med de praktiske kravene til Windows 95 er det brukbart.

Base Server støtter mange prosessorer og mange samtidige oppgaver per prosessor. Disse funksjonene, kalt multithreading og multiprosessering, er først og fremst fristelser for fagfolk, men de gir også mindre virksomheter glimrende tjenestemaskin-egenskaper med to Pentium-prosessorer.

-- Mindre brukere forstår ikke hva multithreading betyr, men de ser at maskinen blir mer effektiv på grunn av denne teknologien. Stadig flere bedrifter setter pris på to prosessorer som gjør at Solaris Base Server kan støtte flere hundre brukere, sier Rolf Rennemo.

Nettverk

Mens SCO Unix opprinnelig var et miljø for mange terminaltilknyttede brukere, er Solaris Base Server et miljø hvor nettverket er helt vesentlig. Nettverksprogramvaren er standard, men kunder kan velge den bort hvis de fremdeles benytter direkte tilkoblete terminaler.

TCP/IP som nettverksprotokoll og ONC for nettverkstjenester for utskrift, filhåndtering, administrasjon og sikkerhet, er standard. Støtte for ATM, Fast Ethernet, FDDI og ISDN er innebygget.

Tilleggsprogramvare sørger for DCE, X25 og IPX-protokollen til Novells Netware.

Sikkerhet er også vesentlig. C2 er standard. ONC+ sørger for autorisasjon ved hjelp av programvare som Diffie-Hellman eller Kerberos 4.0. Ved å benytte DES, Data Encryption Standard, kan data og kartoteker gjøres uleselige for utenforstående. 

                    Solaris Base Server
Solaris Base Server er Sunsofts alternativ til SCOs fremtidige løsning eller Windows NT. Oppgradering fra alle Intelbaserte UNIX-versjoner er en selvfølge.

Krav:

12 MB hukommelse, 100 MB platelager med alle nettverksfunksjonene.

Oppgradering:

Støtter alle programmer tilpasset SCO Unix og Interactive inklusive gammel Xenix-kode.

Pris:

4.415 kroner for to brukere, 8.830 kroner for ubegrenset antall brukere. Oppgradering fra SCO eller Interactive koster 3.615 kroner for ubegrenset antall brukere.

Levering:

På lager.
