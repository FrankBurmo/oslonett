Database-server fra Sybase

Sybase lanserer en rekke produkter i høst. Produktet vi venter mest på er database-serveren SQL Server 11 database. SQL Server 11 database slippes ifølge Sybase i desember.

Men før dette vil selskapet i neste uke lansere en ny versjon av Omniconnect, som er en inngangsport mot andre systemer. Omniconnect 10.5 gir direkte tilgang til Sybase SQL Server og andre databaser som Oracle, Informix, DB2 og Ingress. Tilgangen fåes via en serie plug-inn moduler som kalles Open Access Servers. Omniconnect vil erstatte eksisterende OmniSQL Gateway verktøy.

Sybase vil også i løpet av høsten oppgradere Powersoft og introdusere en Web-server som er integrert med SQL Server. (KG)
