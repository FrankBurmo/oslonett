Forbedrer Windows 95

Norton Navigator gir nyttige tillegg

Microsoft har lagt inn en utrolig mengde verktøy og muligheter i Windows 95, men det er fremdeles rom for forbedringer. Norton Navigator for Windows 95 gir en serie raske og nyttige tillegg, men du må vente til etter 24. august.

Einar Ryvarden

Symantec har alltid gitt PC-brukere nyttige verktøy, men Norton Desktop ble aldri noen kjempesuksess. Den meget omfattende tilleggspakken for Windows 3.x ble for tung og stjal dermed mye ytelse. Dette har Symantec rettet i Navigator for Windows 95.

Symantec er nå den ubestridte lederen på PC-verktøy etter å ha kjøpt opp PC Tools. For Windows 95 planlegger selskapet å lansere tre pakker som tidligere var samlet i Norton Desktop. Utilities for Windows 95 er allerede tilgjengelig for registerte beta-testere av Windows 95. I tillegg er Symantec klar med Navigator, en pakke med en serie nyttige tillegg og Norton Antivirus.

24. august

Windows95-brukere må dessverre vente til etter 24. august, lanseringsdatoen for Windows 95, for å få kjøpe Navigator og Antivirus. Antivirus-modulen er oppdatert mot nye viruser og kan skanne komprimerte filer. Dessuten kan den overvåke og si ifra om viruslignende aktivitet som lavformatering.

Navigator er inndelt i to hovedmoduler -- Control Center og File Manager. File Manager er et alternativ til de forskjellige navigeringsmodulene i Windows 95. File Manager minner om Explorer i Windows 95, men gir en rekke tilleggsverktøy.

Mange av dem, blant annet kryptering og filkomprimering, er kjente verktøy i ny innpakking. Men File Manager er også tilpasset Internet med en innebygget FTP-klient. Du kan også Uuencode-konvertere filer til og fra 7-bits ASCII-formatet som brukes på store deler av Internet.

Ut på desktopen i Windows 95 har du også fått noen nye knapper på "taskbaren" nederst på skjermen. Norton Navigator gir deg muligheten til å lage flere desktop og bytte mellom dem med et klikk på taskbaren. Lengst til høyre ligger dessuten utløserknappen for Control Center.

Control Center

Her ligger samlingen som virkelig gjør Navigator verd pengene. Smartfolder er trolig den mest imponerende. Med dette tillegget kan man sette opp foldere som automatisk samler shortcuts til alle filer av angitte slag. Man kan for eksempel få shortcuts til alle XLS-regneark på to serverdisker som er mindre enn to uker gamle.

Norton Fastfind er en gammel kjenning, men i Navigator lar denne modulen deg nå indeksere hele directories for svært raske tekstsøk. Med i pakken følger også Undo, et tillegg som kan logge de opptil 9.999 siste filoperasjonene. Dette kan være nyttig i en rekke sammenhenger, blant annet for datasjefer som skal rydde opp etter uerfarne brukere.

ALTERNATIV: File Manager i Navigator minner om Explorer i Windows 95, men gir en rekke tilleggsverktøy som kryptering, filkomprimering, FTP-klient og Uuencoding. Fra taskbaren i Windows 95 (nederst på skjermen) kan du bytte mellom forskjellige desktopper med ikoner og mapper.
