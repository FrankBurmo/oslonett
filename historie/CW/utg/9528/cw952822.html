Geografiske data

Maps 3.5 er et Windowsbasert system for presentasjon, illustrasjon og nøyaktig visning av dine geografiske baserte data. Med Maps 3.5 kan du lage dine egne kart som inneholder dine data, hvor man for eksempel kan hvor kundene bor, hvor det er forurensning, hvor det er høyt inntektsnivå og lignende.

I versjon 3.5 kan du importere rasterbilder fra andre programmer, slik at grafer, illustrasjoner og logoer fritt kan plasseres på et kart, du kan produsere tematiske kart utfra egne data, symboler kan plasseres hvor som helst på et kart, og du kan definere egne koordinatsystemer.
