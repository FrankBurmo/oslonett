Ny Web fra Sun

Sun utvikler nytt, sikkert Internet-språk.

I september lanserer Sun Java et nytt språk for sikker kommunikasjon mellom program over Internet. Med Java skal utviklere lage applikasjoner som samspiller og henter data over Internet-linjer med kryptert kommunikasjon.

Java er plattform-uavhengig og Sun planlegger Mac, Windows og Sun-versjoner. En alfa-versjon for Sun er allerede klar, og Sun lover å ha alle tre versjonene klare i september. Java-formatet kan lese filsystemet og tegne skjermbilder under både Sun Solaris, Apple System 7.x, Windows 95 og Windows NT.

Ny Paradox og dBase

Borland slipper ny dBase Paradox 6.0 tre måneder etter Windows 95-lanseringen. Tre måneder etter Windows 95-lanseringen er Borland klar med en 16-bits oppgraderingen av dBase og en 32-bits versjonen av Paradox 6.0. Ifølge Borland håper de å forbedre dBase 5.0s ytelse, brukervennlighet og tilpasningsdyktighet. Voyager vil kunne bruke VBX og et nytt brukergrensesnitt for å gjøre applikasjonsutvikling enklere.

Paradox 6.0 låner en del fra utviklingsmiljøet til Delphi, som oppsett og menyer. For bedre å kunne konkurrere med Microsofts Access database, vil Paradox inneholde bedre integrasjon med Novells Perfectoffice via OLE 2.0 som Paradox er pakket med. Paradox vil også bli bedre integrert med Microsoft Office.

Web-server for Windows

World Wide Web server for Windows 3.x, 95 og NT. Beame & Whiteside Software har lansert Web'd som fungerer under Windows 3.x, Windows 95 og Windows NT. Web'd gjør det enkelt å lage, formatere og endre HTML dokumenter ved hjelp av tekstbehandleren HTML-Edit.

Web'd for Windows støtter alle standard URLer (Universal Resource Locators), og alle de mest populære Web-leserne som Netscape og Mosaic.
