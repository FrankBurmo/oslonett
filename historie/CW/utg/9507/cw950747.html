Ny SNA Server i mars

Microsoft planlegger oppgradering av SNA Server I løpet av mars skal Microsoft lansere en oppgradering av sin Windows NT-baserte SNA Server. Den nye versjonen gir raskere ytelse mot IBMs System Network Arcitecture (SNA). SNA Server 95, som pakken trolig vil hete, gir også forbedret støtte for APPC-protokollen.

Microsoft skal lansere SNA Server 95 for Windows NT både på Intel, Alpha og MIPS-plattformene. I tillegg planlegger selskapet en PowerPC-versjon, men denne må vente til Windows NT Server for PowerPC kommer i salg til sommeren.

Microsoft vil distribuere alle versjonene av SNA på en CD-plate. Serverprogramvaren vil koste rundt 3.500 kroner, mens klientlisensene havner på ca. 500 kroner. Den nye SNA Server 95 inneholder Remote Access Service (RAS) for SNA. Dette gjør det mulig å la lokale nettverk med NT-servere koble seg sammen over SNA uten å gå via en stormaskin eller AS/400, forteller Vesa Suomalainen, sjef for SNA Server hos Microsoft.

RAS for SNA lar nettsjefer administrere tilkoplede lokale nettverk med vanlige verktøy. Med i SNA-pakken fra Microsoft skal følger IBMs APPC-applikasjonspakke med blant annet APPC filoverføringsprotokollen. Dette har Microsoft lisensiert fra IBM (ER).

Filmbransjen satser på klient/tjener

Nytt klient/tjener-system for innsamling av kinotall. Den internasjonale filmbransjen får et nytt markedsføringsverktøy. I april kommer ikke lenger rapportene om besøkstall på kinoene med faks og kurertjenester, men over modem. Entertainment Data Inc som før sendte ur rapporter, legger i april om til et klient/tjener-basert system. Studioene og produksjonsselskapene i USA, Tyskland og England kan da koble seg opp mot EDIs tjener med en PC og hente ut rapporter. Dette gir langt raskere og mer nøyaktige statistikker. Samtidig kan studioene søke etter mer detaljert geografisk informasjon for å planlegge og justere videre distribusjon.

Filmsource, som EDI kaller systemet sitt, er basert på en Informix 7.0 database som går på en åtte-prosessors Sequent server. Klienten er i Gupta SQLWindows. Fordi Informix støtter replikering, kopierer EDI databasen til en server i Tyskland og England. (ER)
