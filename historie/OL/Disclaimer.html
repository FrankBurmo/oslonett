Disclaimer regarding Results from The 1994 Winter Olympics

It is important to be aware of the fact that the HTML rendering of the results received from the NTB wire service may introduce some oddities and peculiarities in the files.

This is due to the fact that the data originally were targeted for human beings, not computer programs. Consequently, there is not very much tagging information to use. The Perl programs try to do their best to extract event information, date-and-time stamps, nationality information and so on, but some errors are likely to occur!

Also, note that all data are originally written in Norwegian. We do some automatically translation on country names and event names, but expect some funny mixed language constructs.

Please tell us (oslonett@oslonett.no) if you see oddities.

We will try to do some post-editing of the files to clean up things, but we will not be able to check every single byte.

Oslonett, Sun Microsystems and Skrivervik Data are not responsible for any inconveniences the above discrepancies may cause you. This is a take-it-or-leave-it service.
