World Wide Web konsulenttjenester

I tillegg til all Web-aktivitet på egne maskiner, gjør vi et utstrakt eksternt konsulentarbeide innenfor World Wide Web relatert virksomhet. Se om ikke også du og din bedrift kan ha glede av dette!
Vår kompetanse innenfor World Wide Web er ettertraktet, og vi kan påta oss små og store konsulentoppdrag innenfor følgende områder:
Oppsett av ulike Web-servere
Vi kjenner de fleste Web-servere på markedet ut og inn, og vil kunne sette opp en server i en bedrift, og lære opp bedriften til å drive serveren selv. Som en del av oppsett og konfigurering, inngår automatisk loggrotasjon, statistikkgenerering mm.
CGI programmering
CGI står for Common Gateway Interface, og er en mekanisme som gjør det mulig fra Web å kommunisere med eksterne applikasjoner i nettet, f.eks. SQL databaser. Vi kan påta oss å lage løsninger for integrasjon mellom Web og de fleste andre applikasjoner som er nåbare via TCP/IP eller andre mekanismer.
Automatisk Web publisering
Gjennom arbeidet med å legge ut aviser som Morgenbladet og Computerworld, har vi opparbeidet god kompetanse på automatisk produksjon av HTML filer ut fra andre formater. Vi kan her utvikle programvare som gjør at bedriften selv kan overta arbeidet med å legge ut aviser, blader og kataloger som kommer med faste mellomrom.
Web som internt informasjonssystem i en bedrift
World Wide Web er absolutt en sterk kandidat for et internet informasjonssystem i en bedrift. Web kan på mange måter sammenliknes med "groupware" som f.eks. Lotus Notes, men Web er enklere å bruke som "informasjonslim" for å knytte sammen interinformasjon på tvers av dataformater, maskinplattformer, programvare og andre skillelinjer.

Vi vil kunne hjelpe til med å planlegge en informasjonsplattform som gjør det effektivt å bruke Web til dette formålet, og vil kunne sette opp rutiner for å komme i gang.
