PC Trafikkskilt (PC Traffic Signs) is an educational drill program for learning and memorizing all more than 200 Norwegian traffic signs, light signals and road markings. The program includes detailed graphics showing all the signs organized in groups as published by the Norwegian road and traffic authorities. The program contains both simple information lookup modes and test modes for testing your skills at recognizing the signs and matching them against their textual meanings or vice versa.

You can download a demonstration version showing only one group of signs but which otherwise demonstrates the full functionality of the program. The complete program can be ordered by sending NOK 375,- incl Norwegian sales tax to Computers and Learning A/S, Gaustadalleen 21, N-0371 Oslo, Norway.

NOTE 1: This program is only avaliable in Norwegian.

NOTE 2: To unpack, use an unzipper like pkunzip. Make sure you retrieve the directory structure (for pkunzip use the '-d'-option: 'pkunzip -d skiltdem.zip'.) Use the command "Start" to run.

Technical information: Runs under DOS on an EGA, VGA or better screen using EGA (640x350x4) 16 color graphics. Requires a mouse.
