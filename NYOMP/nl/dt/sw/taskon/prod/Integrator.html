TASKON/Integrator®

The INTEGRATOR product supports the users with tools for creating models for retrieval and integration of information residing in various external databases or other information sources. Further, INTEGRATOR supports the users with tools for generating end-user interfaces to the retrieval and integration models.

A solution created with INTEGRATOR can be separated into four levels:

  1. Information level:

    This level contains information sources. This will usually be external relational databases, but other sources such as spreadsheet files or APIs of external systems, may also be included. INTEGRATOR may share its information sources with other systems in the custormer's organization. INTEGRATOR contains a large set of functions to handle external relational databases accessed with SQL, including functions for creation of new databases and functions for accessing and updating of existing ones.

  2. Integration level:

    This level contains descriptions of how the different information sources relate to each other and descriptions of which information is to be retrieved/updated. Integration at this level is done e.g. through defining a singular update operation which is an update of two information sources simultaneously. This can be used to ensure consistency between the sources. Integration can also be done by describing a report which combine information from two or more, otherwise unconnected, information sources.

  3. Navigation level:

    This level contains specifications of the paths the end-user may follow when accessing information. This may be based on (combinations of) database queries, filesystem structures, or internal structure of multimedia information resources.

  4. User interface level: This level contains interactive tools which present the lower levels functionality to the end-user. These tools have a common behaviour across all solutions created with INTEGRATOR, although their appearance may vary considerably based on the actual functionality described at the navigation and integration levels.
