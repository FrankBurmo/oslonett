TASKON/OORAM®

The OOram methods and tools provide a comprehensive environment for object oriented analysis, design and implementation in a wide range of application domains such as enterprise modeling, organization development, information management systems, user interfaces, real time systems, and telecommunication systems.

The OOram method and tools support all life cycle stages from early requirements analysis and system architecture trough final system implementation and maintenance. Some customers prefer using other methods and tools such as SDL for parts of the life cycle. The OOram tools have an open architecture permitting integration with such tools.

OOram provides technology for specifying minimum object requirements if they are to support ubiquitous functionality such as exception handling systems, authentication and access control systems, trigger-alert systems, help systems, etc. A superior body such as a standardization agency can specify behavior required of all objects which are to partake in such systems, individual vendors incorporate this behavior into the behavior of their application objects to conform to the standards.

OOram models are represented in an object oriented data base as a coherent whole. Main features:

Divide and conquer:
Powerful facilities for dividing total problem into smaller areas of concern, and creating system models for each area separately.
Multiple views:
Semantic view, collaboration view, message sequence view, data flow view, finite state machine view, program (method) view. All are views on a common model and present a consistent set of pictures of the system being modeled.
Reuse:
With OOram you can reuse ideas, designs, frameworks and application modules from libraries.
Model synthesis
creates composite models from simpler ones in a controlled manner. This is a general composition facility, not restricted to simple hierarchies.
Forward and reverse engineering:
Object Type Specification supports transition from design to implementation in several programming languages such as Smalltalk, Eiffel, C++. Other tools support analysis of an implementation to help designer recreate abstract descriptions. Supports monitored execution where actual program execution is dynamically compared to design specification.

OOram support graphical tools for:

  1. Modelling with role models.
  2. Message Sequence Charts describing the interaction of objects.
  3. Finite state machines describing the behaviour of the objects
  4. Flow charts describing how data flows between the objects.
  5. Type specification as an interface to the implementation.

All the tools support drag and drop functionality.

TASKON/OOram is delivered on Unix workstations (SUN, DEC, HP and IBM) and MS-DOS PCs. The user interface is window based (OSF/Motif or Windows 3.1).
