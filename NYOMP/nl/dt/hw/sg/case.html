Developer Magic

Developer Magic består av flere verktøy for programvareutvikling. Disse verktøyene gjør programmering, kompilering og debugging raskt og enkelt.

  • ProDev Workshop
  • Pro MPF
  • MegaDev
  • RapidApp
  • Tracker
  • ClearCase
  • ViewKit

ProDev Workshop

ProDev Workshop er et utviklingsmiljø som hjelper deg til a visualisere kode. Den er et sett verktøy som benytter en objektorientert applikasjonsramme. WorkShop Toolset inneholder fem grafiske verktøy:

  • Debugger
    WorkShop Debugger er et kildekode debuggings verktøy som gir deg spesielle vinduer for å se data og kjøre status mens program kjører. Debuggeren lar deg benytte forskjellige typer av "traps (breakpoints)" og "watch points".
  • Static Analyzer
    WorkShop Static Analyzer hjelper deg å analysere kildekode som er skrevet i C, C++, eller Fortran ved å vise deg kodens struktur enten i grafisk eller tekst format. Den viser deg hvordan funksjoner innen et program kaller hverandre, hvor variabler er definert, hvor filer er avhengige av hverandre, hvor du kan finne makroer og mange andre strukturelle detaljer som hjelper deg til å forstå koden bedre.
  • Performance Analyzer
    Med Performance Analyzer kan du definere og kjøre eksperimenter som samler ytelsestall. Performance Analyzer bruker disse dataene til å produsere kart, tabeller og annotert kode som hjelper deg til å analysere ytelsen på programmet ditt.
  • Tester
    WorkShop Tester er et kvalitetssikkrings verktøy for programvare og testingeniører og deres sjefer som er involvert i utviklingen, testingen og videreutviklingen av langtids prosjekter.
  • Build Manager
    Du kan bruke WorkShop/Build Manager til å kompilere programvare uten å forlate WorkShop miljøet. Du kan se etter problemområder ved å bruke WorkShop analyse verktøyene (Static Analyzer, Debugger, and Performance Analyzer), gjøre endringer i kildekoden, avbryte testingen og rekompilere. Build Manager består av to komponenter:
    • Build View for kompilering, overvåke lister av kompilerings feil, og akksessere koden som inneholder feilene i Source View (CASEVision editoren) eller en annen editor som du måtte like. Build View hjelper deg å finne filer som inneholder kompileringsfeil så du raskt kan korrigere dem, rekompilere, og fortsette testingen.
    • Build Analyzer for å se "build" avhengigheter og rekompileringsforutsetninger og å akksessere kildekode filer.

Pro MPF

Fortran 77 programmerere kan bruke WorkShop Pro MPF Parallel Analyzer View til å se strukturen i applikasjoner som kjøres på flere prosesser (prosessorer). Dette verktøyet leser analyse-filer som er generert av Power Fortran Accelerator (PFA) og gir en visuell sammenligning mellom den orginale koden og den parallelliserte koden. Dette gir programmereren muligheter til enkelt å evaluere om han/hun skal parallellisere koden eller kjøre den på en uniprosessor løsning.

MegaDev

MegaDev er en pakke av grafiske og interaktive CASE (computer-aided software) verktøy som er utviklet spesielt for programmerere som utvikler og vedlikeholder C++ biblioteker og applikasjoner.

MegaDev inneholder en C++ Browser og "Fix and Continue" funksjonalitet. C++ Browseren lar deg se strukturen i alle C++ klassene og gir deg en global, grafisk oversikt over "interclass relationships" som inheritance, containment, og interaksjon innen et sett av klasser. "Fix and Continue" funksjonaliteten gir deg mulighet til å redefinere funksjoner i ditt program, og du kan fortsette kjøringen uten rekompilering.

RapidApp

RapidApp er et interaktivt verktøy for å lage applikasjoner. Den integrerer med andre Developer Magic verktøy for å tilby et miljø for rask utvikling av objektorienterte applikasjoner. Disse verktøyene er blant annet :

  • cvd,
  • cvstatic,
  • cvbuild,
  • Delta C++,
  • Smart Build,

RapidApp genererer C++ kode, med grensesnitts klasser basert på ViewKit verktøyet. Den predefinerer grensesnitts komponenter hvilket letter din bruk av andre Developer Magic biblioteker som Open GL og Open Inventor.

Du kan bruke RapidApp for å lage typiske applikasjoner hvor brukergrensesnittet har en stor effekt på nytten av den totale applikasjons arkitekturen. Applikasjoner som er produsert med RapidApp er automatisk integrert mot Indigo Magic Desktop miljøet. Det endelige brukergrensesnittet laget av RapidApp bruker OSF/MOTIF verktøyet.

Med RapidApp jobber du med en kombinasjon av OSF/MOTIF widgets og komponenter basert på ViewKit klasser. Du lager, velger, posisjonerer og manipulerer elementer av grensesnittet ved hjelp av teknikker som blir brukt i tegne editorer som for eksempel i Showcase. Du kan flytte elementer av grensesnittet etter å ha laget dem og du kan editere forskjellige attributter (ressurser) for å endre utseende og oppførsel.

Tracker

Tracker er et verktøy for å lage oppfølgingssystemer for feilmeldinger og forespørsler om utvidelser/forbedringer av eksisterende program/prosjekt. Det tillater deg å designe og lage en oppfølgings database, samt brukergrensesnittet mot databasen.

ClearCase

ClearCase er et konfigurasjonsstyrings system som er spesielt egnet for storeskala og langtids orienterte prosjekter. ClearCase håndterer mange forskjellige versjoner av programvaren samtidig, og holder oversikt over disse gjennom prosjektperioden.

ViewKit

ViewKit er et C++ verktøy som gjør det lettere for deg å utvikle applikasjoner. Den tilbyr en kolleksjon av høynivå brukergrensesnitts komponenter (for eksempel vinduer, menyer og dialoger) og andre support fasiliteter som man typisk må implementere i alle typer applikasjoner.

ViewKit inneholder flere sett av klasser :

  • framework classes,
  • interface components,
  • network licensing,
  • interapplication communication,
  • convenience utilities.

ViewKit erstatter ikke OSF/MOTIF eller andre verktøy. Faktisk bruker ViewKit, OSF/MOTIF widgets til å implementere alle grensesnitts komponentene. Du kan også kalle OSF/MOTIF funksjoner direkte, til å lage og manipulere widgets i en ViewKit applikasjon. ViewKit arkitekturen hjelper til å skjule mye av kompleksiteten i å programmere med OSF/MOTIF.
