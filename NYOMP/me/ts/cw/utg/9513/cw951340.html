Microsoft med fjerde betaversjon

Microsoft har nå annonsert den fjerde beta-versjonen av SQL Server 6.0 til over 2.500 testkunder. Dette er den første beta-versjonen Microsoft lanserer etter bruddet med Sybase Inc., som laget den opprinnelige databasekoden.

I versjon 6.0 har Microsoft puttet inn funksjonalitet for data-replikering, en serie grafiske verktøy for å kontrollere SQL-Server sentralt og en ny parallell databasemotor som skal forbedre ytelsen betraktelig.

Microsoft har også sagt at kunder som kjøper lisenser til Microsoft SQL-Server versjon 4.21 for Windows NT, vil få gratis oppgradering til 6.0 når den blir tilgjengelig senere i år. (AL)

Access med Visual Basic

Windows 95 versjonen av Access, Access 95, vil komme med støtte for programmeringsspråket Visual Basic for Applications. Visual Basic for Applications (VBA) benytter samme syntaks som Visual Basic, og lar utviklere få tilgang til deler av andre Microsoft applikasjoner gjennom OLE-objekter. Ved hjelp av dette kan utviklere på en relativt enkel måte sette sammen egne programmer.

Med dette vil Microsoft ta ett steg nærmere å ha et felles makrospråk. VBA er allerede implementert i Excel, Project og Visual Basic. Word kan delta i VBA applikasjoner, men er ikke 100 prosent VBA kompatibel. Den nåværende versjonen av Access har et eget makrospråk, Access Basic, som er 80 prosent kompatibelt med VBA.

Analytikere tror at et felles makrospråk for Microsoft-appliksjonene kan gjøre det vanskeligere for tredjeparts-leverandører å finne en nisje. Oppfatningen er at en tettere integrasjon mellom produktene til Microsoft, vil gjøre at produkter som Borlands Delphi vil få det langt tøffere i tiden som kommer når alle Microsofts kontorstøtte-programmer støtter VBA.

Access 95 skal bli tilgjengelig omtrent samtidig med Windows 95 i år. (AL)
