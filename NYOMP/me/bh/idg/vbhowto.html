Visual Basic How-To Second Edition

Boken for alle som skal gjøre noe seriøst i Visual Basic, enten du er nybegynner eller avansert programmerer. Andre bøker forteller deg hva du kan gjøre, her får du konkret vite hvordan. Lag editor med tekst søk, knapperader og statuslinje i et vindu, styring av lydkort, animerte knapper, flytende pop-up menyer, transparente ikoner, profesjonelle grafer, bruk av DLLer, database programmering osv. Over 100 eksempler på ting du trenger i dit daglige arbeid med Visual Basic med detaljert forklaring av hvordan de fungerer og hvordan du bruker dem. Alle programmene ligger på disketten som følger boken, du trenger ikke taste inn noe selv. Med boken følger også MSGHOOK kontroll som gir deg mulighet til å håndtere Windows meldinger Visual Basic ikke vet om. Med denne kan du gjøre ellers umulige ting som dynamiske forklaringer til menyvalg brukeren peker på, dine egne muse-pekere, lese lavnivå MIDI-meldinger, styre Media Control Interace, lage bilder med "hot spots" brukeren kan trykke på og mye mer. Dette er boken ingen Visual Basic programmerer kan være foruten. Du tjener inn igjen prisen første dagen du bruker den.
